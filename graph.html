🧠 HOW TO THINK ABOUT GRAPHS (READ FIRST)

A graph is just "things" (nodes) and the "connections between them" (edges). The real skill is learning to see a problem as a graph — if you can phrase it as "X connects to Y", it is a graph problem, even when the word "graph" never appears.

IS THIS SECRETLY A GRAPH?   →  name the NODES + the EDGES
────────────────────────────────────────────────────────────
NODES (the "things")        EDGES (the "connections")
  cities                     roads between them
  courses                    "take A before B"  (prerequisite, one-way)
  a grid cell (r,c)          its 4 (or 8) neighbours
  a word  "hit"              every word 1 letter away  "hot"
  a board / lock state       one legal move
  people                     friendships / dislikes

If you can name the nodes and the edges, it IS a graph problem.

Before choosing any algorithm, answer four questions about the graph — they decide everything that follows:

1. DIRECTED or UNDIRECTED?   one-way edges (a→b) or two-way (a—b)?
2. WEIGHTED or UNWEIGHTED?   do edges have a cost, or is every hop = 1?
3. CYCLES possible?          can you loop back? → you need a visited set
4. CONNECTED?               one piece or several? → loop over ALL nodes

Representation. Almost always an adjacency list: a map/array where each node points to its list of neighbours (space O(V+E)). Use a matrix only for dense graphs or O(1) "is there an edge?" checks. Pre-create an entry for every node first, so isolated nodes are not missing.

The two ways to walk a graph — pick by what the problem asks:

BFS — explore in expanding RINGS, level by level   (uses a QUEUE)
      the first time you reach a node = the FEWEST hops to it
      → shortest path in an UNWEIGHTED graph, "minimum moves"

DFS — go as DEEP as possible, then back up        (recursion / stack)
      → connectivity, components, cycle detection,
        "all paths", topological ordering

Weighted shortest path?  → Dijkstra  (a BFS that always pops the
                            cheapest node first, via a min-heap)
Negative weights?        → Bellman-Ford

So every graph problem is three moves: (1) recognise the nodes & edges, (2) choose the walk — BFS for shortest/levels, DFS for structure, Dijkstra when edges have weights, (3) keep a visited set so no node is processed twice. Everything below is the reusable template for each case — but always start from this mental model.

// ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// Pattern A: UNDIRECTED edge list [[u, v], ...]
function buildUndirected(n: number, edges: number[][]): Graph {
  const graph = new Map<number, number[]>();
  for (let i = 0; i < n; i++) graph.set(i, []);   // ⭐ Pre-init ALL nodes
  for (const [u, v] of edges) {
    graph.get(u)!.push(v);
    graph.get(v)!.push(u);  // BOTH directions
  }
  return graph;
}

// Pattern B: DIRECTED edge list [[u, v], ...]  (read the problem: which direction?)
function buildDirected(n: number, edges: number[][]): Graph {
  const graph = new Map<number, number[]>();
  for (let i = 0; i < n; i++) graph.set(i, []);
  for (const [u, v] of edges) graph.get(u)!.push(v);  // ONE direction only
  return graph;
}

// Pattern C: WEIGHTED directed [[u, v, w], ...]
function buildWeighted(n: number, edges: number[][]): WeightedGraph {
  const graph = new Map<number, [number, number][]>();
  for (let i = 0; i < n; i++) graph.set(i, []);
  for (const [u, v, w] of edges) graph.get(u)!.push([v, w]);
  return graph;
}

// ⭐ CRITICAL RULE: Pre-initialize ALL n nodes BEFORE adding edges.
//   Isolated nodes (no edges) must exist as empty lists, not missing map entries.
//   Without pre-init: graph.get(isolatedNode) === undefined → crash on traversal.
//
// DIRECTION TRAP (LC 207/210): "to take a you need b first" → edge is b→a, not a→b.

⚡ SECTION 2.5: TYPESCRIPT GOTCHAS (SDE3 Must-Know)

// GOTCHA 1: Map.get() returns undefined, not empty array
// ❌ WRONG — crashes if node not in graph
for (const neighbor of graph.get(node)) { ... }

// ✅ CORRECT — always use nullish coalescing
for (const neighbor of graph.get(node) ?? []) { ... }

// GOTCHA 2: Array(n).fill([]) shares the SAME array reference
// ❌ WRONG — all rows point to the same array!
const grid = new Array(rows).fill(new Array(cols).fill(0));
grid[0][0] = 1; // This modifies ALL rows!

// ✅ CORRECT — use Array.from with mapping function
const grid = Array.from({ length: rows }, () => new Array(cols).fill(0));

// GOTCHA 3: Sorting numbers with default comparator
// ❌ WRONG — JS default sort is lexicographic, not numeric!
[10, 9, 2, 1].sort() // → [1, 10, 2, 9] ← WRONG for edge sorting!

// ✅ CORRECT — always provide numeric comparator
edges.sort((a, b) => a[2] - b[2]); // sort by weight ascending

// GOTCHA 4: for...of on Map iterates [key, value] pairs
// ❌ WRONG — common confusion
for (const node of graph) { // node is [key, value[]], not just key!
  node.neighbors // undefined!
}

// ✅ CORRECT
for (const [node, neighbors] of graph) { ... }
// OR
for (const node of graph.keys()) { ... }

// GOTCHA 5: Destructuring from heap.pop() when heap is empty
// ❌ WRONG — crashes if heap is empty
const [dist, node] = heap.pop()!;

// ✅ CORRECT — check before destructuring
const entry = heap.pop();
if (!entry) break;
const [dist, node] = entry;

// GOTCHA 6: Modifying array while iterating
// ❌ WRONG — undefined behavior
for (const dest of graph.get(node)!) {
  graph.get(node)!.splice(0, 1); // modifying while iterating = bug
}

// ✅ CORRECT — use while loop with pop()
while (graph.get(node)!.length > 0) {
  const next = graph.get(node)!.pop()!;
  dfs(next);
}

// GOTCHA 7: Infinity arithmetic (safe but sometimes not obvious)
const dist = new Array(n).fill(Infinity);
// Infinity + 5 = Infinity ✓
// Infinity > 100 = true ✓
// 5 < Infinity = true ✓
// This is why Infinity is better than Number.MAX_SAFE_INTEGER for distances

// GOTCHA 8: Number keys vs String keys in Map
// ❌ WRONG — Map treats 1 and "1" as different keys (silent bug!)
const graph = new Map<string, number[]>();
graph.set("1", [2, 3]);
graph.get(1); // undefined! Key is string "1", not number 1

// ✅ CORRECT — Be consistent with key types throughout
// If nodes come as strings from input, keep as strings everywhere
// If nodes are numbers, keep as numbers everywhere
// When in doubt: convert at the boundary once, then stay consistent

🌊 SECTION 3: BFS TEMPLATES (5 Variants)

Shortest path in unweighted graphs, and level-order exploration.

🎤 Interview lens Probed: mark visited on enqueue (not dequeue) and why, the head-pointer vs O(n) shift() trick, and spotting multi-source (seed every source at dist 0). · Escalation: standard BFS → shortest path on a grid → multi-source (994 Rotting Oranges) → bidirectional (b^(d/2)) → 0-1 BFS deque for {0,1} weights.

3.1 Standard BFS (Unweighted Graph)

function bfs(graph: Graph, start: number, n: number): void {
  const visited = new Set<number>([start]);
  const queue: number[] = [start];
  let head = 0; // ⭐ Use index pointer, NOT shift()

  while (head < queue.length) {
    const node = queue[head++];

    // ── PROCESS node HERE ──
    console.log(node);

    for (const neighbor of graph.get(node) ?? []) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor); // ⭐ Mark on ENQUEUE, not dequeue
        // WHY: If you mark on dequeue, the same node can be added to the
        // queue multiple times before being processed. For a graph with high
        // branching factor this causes O(E) duplicates in queue instead of
        // O(V), potentially causing MLE. Mark on enqueue = each node queued once.
        queue.push(neighbor);
      }
    }
  }
}
// Time: O(V+E) Space: O(V)
// Why index pointer? shift() is O(n), pointer is O(1)

3.2 BFS with Distance/Level Tracking

function bfsWithDist(graph: Graph, start: number, n: number): Map<number, number> {
  const dist = new Map<number, number>([[start, 0]]);
  const queue: number[] = [start];
  let head = 0;

  while (head < queue.length) {
    const node = queue[head++];
    const currDist = dist.get(node)!;

    for (const neighbor of graph.get(node) ?? []) {
      if (!dist.has(neighbor)) {
        dist.set(neighbor, currDist + 1);
        queue.push(neighbor);
      }
    }
  }
  return dist;
}

3.3 Multi-Source BFS (LC 994, 286)

function bfsMultiSource(grid: string[][], sources: [number, number][]): number[][] {
  const rows = grid.length,
    cols = grid[0].length;
  const dist: number[][] = Array.from({ length: rows }, () => new Array(cols).fill(-1));
  const queue: [number, number][] = [];

  // Seed all sources with distance 0
  for (const [r, c] of sources) {
    dist[r][c] = 0;
    queue.push([r, c]);
  }

  let head = 0;
  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];

  while (head < queue.length) {
    const [r, c] = queue[head++];

    for (const [dr, dc] of dirs) {
      const nr = r + dr,
        nc = c + dc;
      if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && dist[nr][nc] === -1) {
        dist[nr][nc] = dist[r][c] + 1;
        queue.push([nr, nc]);
      }
    }
  }
  return dist;
}

3.4 Bidirectional BFS (SDE3 Pattern) ⭐

function bidirectionalBFS(start: string, end: string, getNeighbors: (state: string) => string[]): number {
  if (start === end) return 0;

  // ✅ Use Set for frontier: O(1) "already in frontier" check instead of O(n)
  let frontierA = new Set<string>([start]);
  let frontierB = new Set<string>([end]);
  let visitedA = new Set<string>([start]);
  let visitedB = new Set<string>([end]);
  let steps = 0;

  while (frontierA.size > 0 && frontierB.size > 0) {
    steps++;
    // Always expand the smaller frontier (exponential savings)
    if (frontierA.size > frontierB.size) {
      [frontierA, frontierB] = [frontierB, frontierA];
      [visitedA, visitedB] = [visitedB, visitedA];
    }

    const nextFrontier = new Set<string>();
    for (const state of frontierA) {
      for (const neighbor of getNeighbors(state)) {
        if (visitedB.has(neighbor)) return steps; // ✅ Met in middle
        if (!visitedA.has(neighbor)) {
          visitedA.add(neighbor);
          nextFrontier.add(neighbor);
        }
      }
    }
    frontierA = nextFrontier;
  }
  return -1; // unreachable
}
// ⭐ Normal BFS explores O(b^d). Bidirectional explores 2*b^(d/2). EXPONENTIALLY faster.
// Space: O(b^(d/2)) for the frontier sets, not O(V).
// KEY FIX vs array-based: Set frontier = no duplicate nodes across iterations.

3.5 0-1 BFS (Deque - JavaScript Workaround) — Special Case (LC 1368)

function bfs01(graph: Map<number, [number, number][]>, start: number, n: number): number[] {
  const dist = new Array(n).fill(Infinity);
  dist[start] = 0;

  // ✅ CORRECT INDEX MANAGEMENT:
  // Using unshift() shifts the array elements, so we MUST use shift() to pop elements
  // instead of a "head" index pointer, otherwise elements will be skipped/re-processed.
  // ⚠️ WARNING: unshift() is O(n) in JavaScript. In interviews, acknowledge this limitation.
  // For production, use a circular-buffer deque or two-stack implementation.
  const deque: number[] = [start];

  while (deque.length > 0) {
    const node = deque.shift()!;

    for (const [neighbor, weight] of graph.get(node) ?? []) {
      const newDist = dist[node] + weight;
      if (newDist < dist[neighbor]) {
        dist[neighbor] = newDist;
        // Push to front if weight=0, else to back
        if (weight === 0)
          deque.unshift(neighbor);
        else deque.push(neighbor);
      }
    }
  }
  return dist;
}
// Time: O(V+E)
// Use case: Grid where some moves are free (weight=0), some costly (weight=1)
// Example LC: 1368 (Min Cost to Make at Least One Valid Path)
// PRODUCTIONNOTE: unshift() is O(n) — acceptable in interviews if you acknowledge it.
// For optimal O(V+E), use a circular-buffer deque or two-stack deque.
// In LC constraints (V ≤ 10^4), unshift() is fast enough in practice.

🌀 SECTION 4: DFS TEMPLATES (4 Variants)

Explore structure — visited set, recurse; pre vs post controls order.

🎤 Interview lens Probed: recursive vs iterative (stack-overflow safety past ~10⁴ depth), in-place grid marking, and using a Set not path.includes() for membership. · Escalation: connected components → number of islands → all-paths backtracking → clone graph (the map doubles as visited; create the clone before enqueuing).

4.1 DFS Recursive (Cleanest)

function dfs(graph: Graph, node: number, visited: Set<number>): void {
  visited.add(node);

  // ── PRE-ORDER PROCESS ──
  console.log(`entering${node}`);

  for (const neighbor of graph.get(node) ?? []) {
    if (!visited.has(neighbor)) dfs(graph, neighbor, visited);
  }

  // ── POST-ORDER PROCESS ──
  console.log(`leaving${node}`);
}

4.2 DFS Iterative (Stack Overflow Safe)

function dfsIterative(graph: Graph, start: number): void {
  const visited = new Set<number>();
  const stack: number[] = [start];

  while (stack.length > 0) {
    const node = stack.pop()!;

    if (visited.has(node)) continue;
    visited.add(node);

    // Push neighbors in REVERSE order to maintain DFS order
    const neighbors = graph.get(node) ?? [];
    for (let i = neighbors.length - 1; i >= 0; i--) {
      if (!visited.has(neighbors[i])) stack.push(neighbors[i]);
    }
  }
}
//NOTE: Iterative DFS does NOT naturally produce post-order traversal.
// For topological sort or Eulerian path, use RECURSIVE DFS.
// Simulating post-order iteratively requires two stacks or a "processed" flag.
// RULE: If you need post-order, default to recursive unless depth > 10K.

4.3 DFS on Grid (In-Place Marking)

function dfsGridInPlace(grid: string[][], r: number, c: number): void {
  const rows = grid.length,
    cols = grid[0].length;

  if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] !== '1') return;

  grid[r][c] = '#'; // ⭐ Mark visited by modifying grid

  dfsGridInPlace(grid, r + 1, c);
  dfsGridInPlace(grid, r - 1, c);
  dfsGridInPlace(grid, r, c + 1);
  dfsGridInPlace(grid, r, c - 1);
}

function dfsBacktrack(

  if (node === target) {
    allPaths.push([...path]); // ⭐ O(V) operation to clone array
    return;

  for (const neighbor of graph.get(node) ?? []) {
    if (!visited.has(neighbor)) {
      // ✅ O(1) lookup

      path.push(neighbor);

      dfsBacktrack(graph, neighbor, target, path, visited, allPaths);

      path.pop(); // ✅ BACKTRACK
      visited.delete(neighbor);
    }
  }
}

class _GraphNode {
  val: number; neighbors: _GraphNode[];
  constructor(val = 0) { this.val = val; this.neighbors = []; }

function cloneGraph(node: _GraphNode | null): _GraphNode | null {
  if (!node) return null;

  // Map: original node → its clone. Doubles as visited set.
  const cloneMap = new Map<_GraphNode, _GraphNode>();

  // ⭐ KEY: Create clone BEFORE enqueuing so neighbor wiring never creates duplicates
  cloneMap.set(node, new _GraphNode(node.val));
  const queue: _GraphNode[] = [node];
  let head = 0;

  while (head < queue.length) {
    const curr = queue[head++];
    const currClone = cloneMap.get(curr)!;

    for (const neighbor of curr.neighbors) {
      if (!cloneMap.has(neighbor)) {
        cloneMap.set(neighbor, new _GraphNode(neighbor.val));
        queue.push(neighbor);
      }
      currClone.neighbors.push(cloneMap.get(neighbor)!); // wire cloned neighbor
    }
  }
  return cloneMap.get(node)!;
}

// ⭐ MINHEAP IMPLEMENTATION (REQUIRED for Dijkstra, Prim's, any heap-based algorithm)
class MinHeap<T> {
  private heap: T[] = [];
  private compareFn: (a: T, b: T) => number;

  constructor(compareFn: (a: T, b: T) => number) {
    this.compareFn = compareFn;
  }

  // Push a value onto the heap
  push(val: T): void {
    this.heap.push(val);
    this.bubbleUp(this.heap.length - 1);
  }

  // Pop the minimum (root) from the heap
  pop(): T | undefined {
    if (this.heap.length === 0) return undefined;
    if (this.heap.length === 1) return this.heap.pop();

    const root = this.heap[0];
    this.heap[0] = this.heap.pop()!;
    this.bubbleDown(0);
    return root;
  }

  // Peek the minimum without removing
  peek(): T | undefined {
    return this.heap[0];
  }

  // Check if empty
  isEmpty(): boolean {
    return this.heap.length === 0;
  }

  // Helper: bubble up (sift up)
  private bubbleUp(i: number): void {
    while (i > 0) {
      const parentIdx = Math.floor((i - 1) / 2);
      if (this.compareFn(this.heap[i], this.heap[parentIdx]) < 0) {
        [this.heap[i], this.heap[parentIdx]] = [this.heap[parentIdx], this.heap[i]];
        i = parentIdx;
      } else {
        break;
      }
    }
  }

  // Helper: bubble down (sift down)
  private bubbleDown(i: number): void {
    while (true) {
      let smallest = i;
      const left = 2 * i + 1;
      const right = 2 * i + 2;

      if (left < this.heap.length && this.compareFn(this.heap[left], this.heap[smallest]) < 0) {
        smallest = left;
      }
      if (right < this.heap.length && this.compareFn(this.heap[right], this.heap[smallest]) < 0) {
        smallest = right;
      }

      if (smallest !== i) {
        [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]];
        i = smallest;
      } else {
        break;
      }
    }
  }
}

5.1 Dijkstra (Weighted, Non-Negative)

function dijkstra(graph: WeightedGraph, start: number, n: number): number[] {
  const dist = new Array(n).fill(Infinity);
  dist[start] = 0;

  const heap = new MinHeap<[number, number]>((a, b) => a[0] - b[0]);
  heap.push([0, start]); // [distance, node]

  while (!heap.isEmpty()) {
    const [d, node] = heap.pop()!;

    // ⭐ CRITICAL: Stale entry check ("Lazy Deletion")
    // Because we can't do O(1) decreaseKey in JS/TS, we push duplicates.
    // This check ignores the older, worse distances.
    if (d > dist[node]) continue;

    for (const [neighbor, weight] of graph.get(node) ?? []) {
      const newDist = dist[node] + weight;
      if (newDist < dist[neighbor]) {
        dist[neighbor] = newDist;
        heap.push([newDist, neighbor]);
      }
    }
  }
  return dist;
}
// Time: O(E log E) or O(E log V) — with lazy deletion, E pushes at O(log E) each.
// Space: O(V + E) for the heap and dist array.
// ❌ DON'T use with negative weights (use Bellman-Ford instead)

5.2 Bellman-Ford (Negative Weights OK)

function bellmanFord(n: number, edges: number[][], start: number): number[] | null {
  const dist = new Array(n).fill(Infinity);
  dist[start] = 0;

  // Relax edges V-1 times
  for (let i = 0; i < n - 1; i++) {
    for (const [u, v, w] of edges) {
      if (dist[u] !== Infinity && dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
      }
    }
  }

  // Check for negative cycles
  for (const [u, v, w] of edges) {
    if (dist[u] !== Infinity && dist[u] + w < dist[v]) {
      return null; // negative cycle detected
    }
  }
  return dist;
}

5.3 Bellman-Ford with K-Stops Limit (LC 787)

function cheapestFlights(n: number, flights: number[][], src: number, dst: number, k: number): number {
  let dist = new Array(n).fill(Infinity);
  dist[src] = 0;

  // ✅ CRITICAL: "k stops" = k INTERMEDIATE cities (not counting source/destination).
  // Example: JFK → (stop1) → (stop2) → LAS = 2 stops = 3 edges total
  // Loop must run k+1 times because: i=0,1,2,...,k means k+1 relaxations
  // Source → intermediate[0] → intermediate[1] → ... → intermediate[k-1] → destination
  // TRAP: Writing i < k (k iterations only) gives WRONG ANSWER — off by one!
  for (let i = 0; i <= k; i++) {
    const nextDist = [...dist]; // MUST copy to prevent value bleed within same iteration
    let updated = false;

    for (const [u, v, price] of flights) {
      if (dist[u] !== Infinity && dist[u] + price < nextDist[v]) {
        nextDist[v] = dist[u] + price;
        updated = true;
      }
    }

    dist = nextDist;
    if (!updated) break; // ✅ Early exit if no improvement
  }

  return dist[dst] === Infinity ? -1 : dist[dst];
}

5.4 Floyd-Warshall (All Pairs)

function floydWarshall(n: number, edges: number[][]): number[][] | null {
  const dist: number[][] = Array.from({ length: n }, () => new Array(n).fill(Infinity));
  for (let i = 0; i < n; i++) dist[i][i] = 0;
  for (const [u, v, w] of edges) {
    dist[u][v] = Math.min(dist[u][v], w);
    // For UNDIRECTED graphs: also set dist[v][u] = Math.min(dist[v][u], w);
  }

  // For each intermediate node k
  for (let k = 0; k < n; k++) {
    for (let i = 0; i < n; i++) {
      for (let j = 0; j < n; j++) {
        if (dist[i][k] !== Infinity && dist[k][j] !== Infinity) {
          dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
        }
      }
    }
  }

  // ✅ Check for negative cycles
  for (let i = 0; i < n; i++) {
    if (dist[i][i] < 0) return null; // Negative cycle detected
  }
  return dist;
}
// Time: O(V³) Space: O(V²) — Only viable for small graphs (V ≤ 500)

5.5 Dijkstra on Grid (LC 1631, 778, 1368)

// Many LC problems are Dijkstra on a grid, not a graph. Use this when
// grid cells have varying costs and you need min-cost path.
function dijkstraGrid(grid: number[][], start: [number, number], end: [number, number]): number {
  const rows = grid.length,
    cols = grid[0].length;
  const dist = Array.from({ length: rows }, () => new Array(cols).fill(Infinity));
  dist[start[0]][start[1]] = 0;

  const heap = new MinHeap<[number, number, number]>((a, b) => a[0] - b[0]);
  heap.push([0, start[0], start[1]]);

  while (!heap.isEmpty()) {
    const [d, r, c] = heap.pop()!;
    if (r === end[0] && c === end[1]) return d;
    if (d > dist[r][c]) continue; // stale entry check

    for (const [dr, dc] of [
      [0, 1],
      [0, -1],
      [1, 0],
      [-1, 0],
    ]) {
      const nr = r + dr,
        nc = c + dc;
      if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
      const newDist = dist[r][c] + grid[nr][nc];
      if (newDist < dist[nr][nc]) {
        dist[nr][nc] = newDist;
        heap.push([newDist, nr, nc]);
      }
    }
  }
  return dist[end[0]][end[1]];
}

// FOLLOW-UP: "Don't just return the distance — return the actual path."
// Works for both BFS and Dijkstra. Track prev[] parent array.

function dijkstraWithPath(graph: WeightedGraph, start: number, end: number, n: number): number[] {
  const dist = new Array(n).fill(Infinity);
  const prev = new Array(n).fill(-1); // ← track parent on shortest path
  dist[start] = 0;

  const heap = new MinHeap<[number, number]>((a, b) => a[0] - b[0]);
  heap.push([0, start]);

  while (!heap.isEmpty()) {
    const [d, node] = heap.pop()!;
    if (d > dist[node]) continue;    // stale
    if (node === end) break;         // ⭐ early exit once target popped

    for (const [neighbor, weight] of graph.get(node) ?? []) {
      const newDist = d + weight;
      if (newDist < dist[neighbor]) {
        dist[neighbor] = newDist;
        prev[neighbor] = node;       // ← record parent
        heap.push([newDist, neighbor]);
      }
    }
  }

  if (dist[end] === Infinity) return []; // unreachable

  // Reconstruct: walk prev[] backwards from end → start, then reverse
  const path: number[] = [];
  for (let cur = end; cur !== -1; cur = prev[cur]) path.push(cur);
  return path.reverse();
}

6.1 Kruskal’s Algorithm (Sort Edges)

function kruskal(n: number, edges: number[][]): number {
  edges.sort((a, b) => a[2] - b[2]); // Sort by weight
  const uf = new UnionFind(n);
  let mstCost = 0,
    edgesAdded = 0;

  for (const [u, v, w] of edges) {
    if (uf.union(u, v)) {
      mstCost += w;
      edgesAdded++;
      if (edgesAdded === n - 1) break;
    }
  }
  return edgesAdded === n - 1 ? mstCost : -1;
}
// Time: O(E log E) Space: O(V)
// Use when: sparse graph, edges easily enumerable

6.2 Prim’s Algorithm (Start from Vertex)

function prims(graph: WeightedGraph, n: number): number {
  const visited = new Set<number>();
  const heap = new MinHeap<[number, number]>((a, b) => a[0] - b[0]);
  heap.push([0, 0]); // [weight, node]
  let mstCost = 0;

  while (!heap.isEmpty() && visited.size < n) {
    const [weight, node] = heap.pop()!;
    if (visited.has(node)) continue; // Stale entry check (lazy deletion)

    visited.add(node);
    mstCost += weight;

    for (const [neighbor, w] of graph.get(node) ?? []) {
      if (!visited.has(neighbor)) heap.push([w, neighbor]);
    }
  }
  return visited.size === n ? mstCost : -1;
}
// Time: O(E log V) Space: O(V + E)
// Note: This uses lazy deletion (same as Dijkstra). O((V+E)logV) only with Fibonacci heap + decreaseKey.

🔗 SECTION 7: UNION-FIND (Path Compression + Rank + Size)

Dynamic connectivity in near-O(1) — undirected graphs only.

🎤 Interview lens Probed: path compression + union-by-rank together give O(α(n)), and why UF is the wrong tool on a directed graph. · Escalation: count components (323) → redundant connection (684) → accounts merge (721) → dynamic connectivity; keep a count field for O(1) component count.
class UnionFind {
  parent: number[];
  rank: number[];
  sizeArr: number[]; // ⭐ Added for SDE3 questions asking for component size

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
    this.sizeArr = new Array(n).fill(1);
  }

  find(x: number): number {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]); // Path compression
    }
    return this.parent[x];
  }

  union(x: number, y: number): boolean {
    const rootX = this.find(x);
    const rootY = this.find(y);
    if (rootX === rootY) return false;

    // Union by rank
    if (this.rank[rootX] < this.rank[rootY]) {
      this.parent[rootX] = rootY;
      this.sizeArr[rootY] += this.sizeArr[rootX];
    } else if (this.rank[rootX] > this.rank[rootY]) {
      this.parent[rootY] = rootX;
      this.sizeArr[rootX] += this.sizeArr[rootY];
    } else {
      this.parent[rootY] = rootX;
      this.sizeArr[rootX] += this.sizeArr[rootY];
      this.rank[rootX]++;
    }
    return true;
  }

  getSize(x: number): number {
    return this.sizeArr[this.find(x)];
  }

  connected(x: number, y: number): boolean {
    return this.find(x) === this.find(y);
  }

  countComponents(): number {
    const roots = new Set<number>();
    for (let i = 0; i < this.parent.length; i++) {
      roots.add(this.find(i));
    }
    return roots.size;
  }
  // countComponents() → LC 323 and similar. NOTE: O(n) — iterates all nodes.
  // For O(1) count per union(), add: private count: number; init to n, decrement in union().
}

📊 SECTION 8: TOPOLOGICAL SORT

Order a DAG — Kahn (peel indegree-0) or DFS post-order reversed.

🎤 Interview lens Probed: Kahn doubling as cycle detection (result.length < n), and swapping the queue for a MinHeap to get the lexicographically smallest order. · Escalation: course schedule I/II (207/210) → Alien Dictionary (building the graph from adjacent word pairs is the hard part) → parallel courses / longest path in a DAG.

// Use DFS: Need to find ALL valid topological sorts (via backtracking), or memory is extremely tight.

8.1 Kahn’s Algorithm (BFS-based)

function topologicalSortKahn(graph: Graph, n: number): number[] {
  const indegree = new Array(n).fill(0);

  for (let i = 0; i < n; i++) {
    for (const neighbor of graph.get(i) ?? []) indegree[neighbor]++;
  }

  const queue: number[] = [];
  for (let i = 0; i < n; i++) {
    if (indegree[i] === 0) queue.push(i);
  }

  const result: number[] = [];
  let head = 0;

  while (head < queue.length) {
    const node = queue[head++];
    result.push(node);

    for (const neighbor of graph.get(node) ?? []) {
      indegree[neighbor]--;
      if (indegree[neighbor] === 0) queue.push(neighbor);
    }
  }
  return result.length === n ? result : []; // Cycle if lengths don't match
  // WHY this works: Nodes in a cycle never reach indegree=0, so they're never
  // added to the queue. Result has fewer than n nodes → cycle detected.
  // This kills two birds with one stone: ordering + cycle detection in one pass.
  // Interviewers love this — it's the SIMPLEST directed cycle detection.
}

8.2 DFS-based Topo Sort (3-Color)

function topologicalSortDFS(graph: Graph, n: number): number[] {
  const color = new Array(n).fill(0); // 0=white, 1=gray, 2=black
  const result: number[] = [];
  let hasCycle = false;

  function dfs(node: number): void {
    if (hasCycle) return;
    if (color[node] === 1) {
      hasCycle = true;
      return;
    }
    if (color[node] === 2) return;

    color[node] = 1; // Visiting
    for (const neighbor of graph.get(node) ?? []) dfs(neighbor);

    color[node] = 2; // Done
    result.push(node); // Add POST-order
  }

  for (let i = 0; i < n; i++) {
    if (color[i] === 0) dfs(i);
  }
  return hasCycle ? [] : result.reverse();
}

8.3 Alien Dictionary (LC 269) — Graph Build + Kahn's ⭐⭐⭐ SDE3

// SIGNAL: "Given a sorted word list from an unknown language, find the character ordering."
// APPROACH: Extract character ordering by comparing adjacent words → directed graph → Kahn's.

function alienOrder(words: string[]): string {
  // Step 1: Add ALL unique characters as nodes (in-degree 0)
  const inDegree = new Map<string, number>();
  const graph = new Map<string, string[]>();
  for (const word of words) {
    for (const ch of word) {
      if (!inDegree.has(ch)) {
        inDegree.set(ch, 0);
        graph.set(ch, []);
      }
    }
  }

  // Step 2: Extract ordering edges from adjacent word pairs
  for (let i = 0; i < words.length - 1; i++) {
    const w1 = words[i], w2 = words[i + 1];
    const minLen = Math.min(w1.length, w2.length);
    let found = false;
    for (let j = 0; j < minLen; j++) {
      if (w1[j] !== w2[j]) {
        graph.get(w1[j])!.push(w2[j]);                    // w1[j] comes before w2[j]
        inDegree.set(w2[j], inDegree.get(w2[j])! + 1);
        found = true;
        break;  // ⭐ ONLY first differing char gives the constraint
      }
    }
    // ⚠️ TRAP 1: ["abc", "ab"] → longer word is a prefix of shorter → INVALID
    if (!found && w1.length > w2.length) return "";
  }

  // Step 3: Kahn's topological sort on character graph
  const queue: string[] = [];
  for (const [ch, deg] of inDegree) {
    if (deg === 0) queue.push(ch);
  }
  let head = 0;
  const result: string[] = [];
  while (head < queue.length) {
    const ch = queue[head++];
    result.push(ch);
    for (const next of graph.get(ch)!) {
      inDegree.set(next, inDegree.get(next)! - 1);
      if (inDegree.get(next) === 0) queue.push(next);
    }
  }

  // ⚠️ TRAP 2: cycle in graph (contradictory ordering) → result misses some chars
  return result.length === inDegree.size ? result.join("") : "";
}

9.1 Undirected Graph (DFS + Parent Check)

function hasCycleUndirected(graph: Graph, n: number): boolean {
  const visited = new Set<number>();

  function dfs(node: number, parent: number): boolean {
    visited.add(node);
    for (const neighbor of graph.get(node) ?? []) {
      if (!visited.has(neighbor)) {
        if (dfs(neighbor, node)) return true;
      } else if (neighbor !== parent) {
        return true; // Back edge found (not the edge we came from)
      }
    }
    return false;
  }

  for (let i = 0; i < n; i++) {
    if (!visited.has(i)) {
      if (dfs(i, -1)) return true;
    }
  }
  return false;
}
// ⚠️NOTE: For multigraphs or edge-list based graphs, track edge index instead of parent node

9.2 Directed Graph (DFS 3-Color)

// WHY 3 colors work:
// White (0) = never visited
// Gray  (1) = currently in DFS stack (ancestor in current path)
// Black (2) = fully processed, no cycle through this node
//
// Back edge to GRAY node = cycle (we found our own ancestor)
// Back edge to BLACK node = safe (already proven no cycle)
//
// ⚠️ TRAP: Using boolean visited[] instead of 3-color for directed graphs.
// Boolean visited[] misses cycles because a node can be visited via
// multiple paths. Gray/Black distinction is MANDATORY for directed graphs.
function hasCycleDirected(graph: Graph, n: number): boolean {
  const color = new Array(n).fill(0); // 0=white, 1=gray, 2=black

  function dfs(node: number): boolean {
    color[node] = 1; // Gray: in current DFS path
    for (const neighbor of graph.get(node) ?? []) {
      if (color[neighbor] === 1) return true; // Back edge to ancestor = cycle
      if (color[neighbor] === 0 && dfs(neighbor)) return true;
    }
    color[node] = 2; // Black: fully processed
    return false;
  }

  for (let i = 0; i < n; i++) {
    if (color[i] === 0) {
      if (dfs(i)) return true;
    }
  }
  return false;
}

function isBipartite(graph: number[][]): boolean {
  const n = graph.length;
  const color = new Array(n).fill(-1);

  // ⭐ KEY INSIGHT: A graph is bipartite IF AND ONLY IF it has no odd-length cycles.
  // 2-coloring BFS fails (same-color conflict) exactly when an odd cycle exists.
  // So bipartite check = odd cycle detection (same algorithm, different framing).
  //
  // COMMON INTERVIEW REFRAMES — all three are the SAME problem:
  // "Can you divide people into 2 groups where no two in same group conflict?" → LC 886
  // "Can you 2-color this graph?"                                             → LC 785
  // "Is this graph bipartite?"                                                → LC 785
  //
  // ⚠️ TRAP: Must handle DISCONNECTED graphs (outer for loop handles this ✓).
  // A disconnected graph is bipartite if EACH component is bipartite.
  // Missing the outer loop = wrong answer on disconnected inputs.

  for (let start = 0; start < n; start++) {
    if (color[start] !== -1) continue;

    const queue = [start];
    color[start] = 0;
    let head = 0;

    while (head < queue.length) {
      const node = queue[head++];
      for (const neighbor of graph[node]) {
        if (color[neighbor] === -1) {
          color[neighbor] = 1 - color[node]; // Flip color
          queue.push(neighbor);
        } else if (color[neighbor] === color[node]) {
          return false; // Same color = not bipartite
        }
      }
    }
  }
  return true;
}
// DFS variant (same logic, useful when recursion is more natural)
function isBipartiteDFS(graph: number[][]): boolean {
  const n = graph.length;
  const color = new Array(n).fill(-1);

  function dfs(node: number, c: number): boolean {
    color[node] = c;
    for (const neighbor of graph[node]) {
      if (color[neighbor] === -1) {
        if (!dfs(neighbor, 1 - c)) return false;
      } else if (color[neighbor] === c) {
        return false; // Same color = conflict
      }
    }
    return true;
  }

  for (let i = 0; i < n; i++) {
    if (color[i] === -1) {
      if (!dfs(i, 0)) return false;
    }
  }
  return true;
}

🛤️ SECTION 11: EULERIAN PATH (Hierholzer’s Algorithm) ⭐ SDE3

Use when asked to “reconstruct an itinerary” or “use every edge exactly once” (LC 332).

function findItinerary(tickets: [string, string][]): string[] {
  // 1. Build Graph (sort destinations for lexical order if required)
  const graph = new Map<string, string[]>();
  for (const [u, v] of tickets) {
    if (!graph.has(u)) graph.set(u, []);
    graph.get(u)!.push(v);
  }
  // Sort descending so we can pop() from the end in O(1) time
  // WHY sort descending then pop():
  // pop() from end = O(1). shift() from front = O(n).
  // Sorting descending puts the lexically smallest at theEND.
  // pop() gives us the smallest in O(1) — if you used ascending + shift(), total cost
  // would be O(E²) instead of O(E log E). Worth explaining to interviewer.
  for (const [_, dests] of graph) dests.sort((a, b) => b.localeCompare(a));

  const path: string[] = [];

  // 2. Post-order DFS
  function dfs(node: string) {
    const dests = graph.get(node) ?? [];
    while (dests.length > 0) {
      const next = dests.pop()!; // Remove edge as we traverse
      dfs(next);
    }
    path.push(node); // Add post-order
  }

  dfs('JFK');
  return path.reverse();
}

// SDE3 SIGNAL: Verify Eulerian path/circuit existence BEFORE running Hierholzer's.
// LC 332 guarantees valid input, but real interviews may not.
function canFormEulerianPath(graph: Map<string, string[]>): boolean {
  const outDegree = new Map<string, number>();
  const inDegree = new Map<string, number>();

  for (const [node, dests] of graph) {
    outDegree.set(node, (outDegree.get(node) ?? 0) + dests.length);
    for (const dest of dests) {
      inDegree.set(dest, (inDegree.get(dest) ?? 0) + 1);
    }
  }

  // Eulerian CIRCUIT:  every node has equal in/out degree
  // Eulerian PATH:     exactly one node has out-in=+1 (start)
  //                    exactly one node has in-out=+1 (end)
  //                    all others have equal in/out degree
  let startNodes = 0,
    endNodes = 0;
  const allNodes = new Set([...outDegree.keys(), ...inDegree.keys()]);

  for (const node of allNodes) {
    const out = outDegree.get(node) ?? 0;
    const inD = inDegree.get(node) ?? 0;
    const diff = out - inD;
    if (diff === 1) startNodes++;
    else if (diff === -1) endNodes++;
    else if (diff !== 0) return false; // Invalid
  }

  return (
    (startNodes === 0 && endNodes === 0) || // Circuit
    (startNodes === 1 && endNodes === 1)
  ); // Path
}

function kosaraju(graph: Graph, n: number): number[][] {
  // Step 1: DFS to get finish times
  const visited = new Set<number>();
  const finishStack: number[] = [];

  function dfs1(node: number): void {
    visited.add(node);
    for (const neighbor of graph.get(node) ?? []) {
      if (!visited.has(neighbor)) dfs1(neighbor);
    }
    finishStack.push(node); // Push AFTER visiting children
  }

  for (let i = 0; i < n; i++) {
    if (!visited.has(i)) dfs1(i);
  }

  // Step 2: Build reversed graph
  const revGraph: Graph = new Map();
  for (let i = 0; i < n; i++) revGraph.set(i, []);
  for (const [node, neighbors] of graph) {
    for (const neighbor of neighbors) revGraph.get(neighbor)!.push(node);
  }

  // Step 3: DFS on reversed graph in reverse finish order
  visited.clear();
  const sccs: number[][] = [];

  function dfs2(node: number, component: number[]): void {
    visited.add(node);
    component.push(node);
    for (const neighbor of revGraph.get(node) ?? []) {
      if (!visited.has(neighbor)) dfs2(neighbor, component);
    }
  }

  while (finishStack.length > 0) {
    const node = finishStack.pop()!;
    if (!visited.has(node)) {
      const component: number[] = [];
      dfs2(node, component);
      sccs.push(component);
    }
  }
  return sccs;
}

🌉 SECTION 13: BRIDGES & ARTICULATION POINTS (OPTIONAL)

function findBridges(graph: Graph, n: number): number[][] {
  const disc = new Array(n).fill(-1);
  const low = new Array(n).fill(-1);
  const bridges: number[][] = [];
  let timer = 0;

  function dfs(node: number, parent: number): void {
    disc[node] = low[node] = timer++;

    for (const neighbor of graph.get(node) ?? []) {
      if (disc[neighbor] === -1) {
        // Tree edge
        dfs(neighbor, node);
        low[node] = Math.min(low[node], low[neighbor]);

        // Bridge condition: cannot reach ancestor from subtree
        if (low[neighbor] > disc[node]) {
          bridges.push([node, neighbor]);
        }
      } else if (neighbor !== parent) {
        // Back edge
        low[node] = Math.min(low[node], disc[neighbor]);
      }
    }
  }

  for (let i = 0; i < n; i++) {
    if (disc[i] === -1) dfs(i, -1);
  }
  return bridges;
}
// Bridge = edge whose removal disconnects graph
// Use: LC 1192 (Critical Connections in Network)
// ⚠️ MULTIGRAPH TRAP: If parallel edges can exist between same two nodes, track
//   EDGE INDEX as parent, not node ID. Two parallel edges A→B: traversing second
//   edge back sees neighbor===parent by node, but it's NOT the same edge → false bridge.
//   Fix: pass parentEdgeIdx instead of parentNode to dfs().
function findArticulationPoints(graph: Graph, n: number): number[] {
  const disc = new Array(n).fill(-1);
  const low = new Array(n).fill(-1);
  const isAP = new Array(n).fill(false);
  let timer = 0;

  function dfs(node: number, parent: number): void {
    disc[node] = low[node] = timer++;
    let childCount = 0; // Only matters for root node

    for (const neighbor of graph.get(node) ?? []) {
      if (disc[neighbor] === -1) {
        childCount++;
        dfs(neighbor, node);
        low[node] = Math.min(low[node], low[neighbor]);

        // AP condition 1: root of DFS tree with 2+ children
        if (parent === -1 && childCount > 1) isAP[node] = true;

        // AP condition 2: non-root where subtree can't reach above node
        if (parent !== -1 && low[neighbor] >= disc[node]) isAP[node] = true;
      } else if (neighbor !== parent) {
        low[node] = Math.min(low[node], disc[neighbor]);
      }
    }
  }

  for (let i = 0; i < n; i++) {
    if (disc[i] === -1) dfs(i, -1);
  }

  return Array.from({ length: n }, (_, i) => i).filter(i => isAP[i]);
}

14.1 Word Ladder (LC 127) — State = String

// Nodes = Words, Edges = 1 char diff. Don't build graph, generate neighbors on the fly.
function ladderLength(beginWord: string, endWord: string, wordList: string[]): number {
  const wordSet = new Set(wordList);
  if (!wordSet.has(endWord)) return 0;

  const queue: [string, number][] = [[beginWord, 1]];
  const visited = new Set<string>([beginWord]);
  let head = 0;

  while (head < queue.length) {
    const [word, steps] = queue[head++];

    for (let i = 0; i < word.length; i++) {
      for (let c = 97; c <= 122; c++) {
        // 'a' to 'z'
        const newWord = word.slice(0, i) + String.fromCharCode(c) + word.slice(i + 1);
        if (newWord === endWord) return steps + 1;

        if (wordSet.has(newWord) && !visited.has(newWord)) {
          visited.add(newWord);
          queue.push([newWord, steps + 1]);
        }
      }
    }
  }
  return 0;
}

14.2 Multi-Dimensional State (LC 1293, 864)

// State = (row, col, eliminations_remaining). Use 3D visited boolean array.
// WHY visited boolean not dist comparison:
// BFS processes states level by level (each level = +1 step).
// First time we reach a state = guaranteed shortest path to that state.
// No need to track distance — just mark visited and move on.
// Using dist comparison (Dijkstra style) in BFS = correct but wasteful:
// it allows the same state to be queued multiple times unnecessarily.
function shortestPathObstacles(grid: number[][], k: number): number {
  const rows = grid.length,
    cols = grid[0].length;
  // Optimization: if k >= Manhattan distance, answer is direct path
  if (k >= rows + cols - 2) return rows + cols - 2;

  // visited[r][c][elim] = have we visited this state?
  const visited = Array.from({ length: rows }, () => Array.from({ length: cols }, () => new Array(k + 1).fill(false)));

  visited[0][0][k] = true;
  const queue: [number, number, number, number][] = [[0, 0, k, 0]]; // [r, c, elim_left, steps]
  let head = 0;

  while (head < queue.length) {
    const [r, c, elim, steps] = queue[head++];

    if (r === rows - 1 && c === cols - 1) return steps;

    for (const [dr, dc] of [
      [0, 1],
      [0, -1],
      [1, 0],
      [-1, 0],
    ]) {
      const nr = r + dr,
        nc = c + dc;
      if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;

      const newElim = grid[nr][nc] === 1 ? elim - 1 : elim;
      if (newElim < 0) continue;

      // ✅ BFS: first visit = shortest path, skip if already visited
      if (!visited[nr][nc][newElim]) {
        visited[nr][nc][newElim] = true;
        queue.push([nr, nc, newElim, steps + 1]);
      }
    }
  }
  return -1;
}

14.3 Binary Search + BFS/DFS Feasibility (LC 778, alt for 1631) ⭐

// SIGNAL: Answer is a min/max threshold AND "can I reach target if threshold ≤ X?"
// is answerable with a simple BFS/DFS. Binary search on X, BFS as oracle.
//
// WHEN TO USE vs DIJKSTRA:
//   BFS oracle is simpler than edge relaxation (just filter cells ≤ threshold)
//   Problem gives discrete bounded answer range (e.g., grid values 0..n²-1)
//   You blanked on Dijkstra under pressure — this is the viable fallback
//   Same complexity as Dijkstra on grid: O(n² log n)
//
// EXAMPLE: LC 778 Swim in Rising Water
function swimInRisingWater(grid: number[][]): number {
  const n = grid.length;
  const DIRS = [[0,1],[0,-1],[1,0],[-1,0]];

  // Oracle: can we reach (n-1,n-1) if max allowed cell value = t?
  function canReach(t: number): boolean {
    if (grid[0][0] > t) return false;
    const visited = Array.from({ length: n }, () => new Array(n).fill(false));
    visited[0][0] = true;
    const queue: [number, number][] = [[0, 0]];
    let head = 0;
    while (head < queue.length) {
      const [r, c] = queue[head++];
      if (r === n-1 && c === n-1) return true;
      for (const [dr, dc] of DIRS) {
        const nr = r+dr, nc = c+dc;
        if (nr >= 0 && nr < n && nc >= 0 && nc < n && !visited[nr][nc] && grid[nr][nc] <= t) {
          visited[nr][nc] = true;
          queue.push([nr, nc]);
        }
      }
    }
    return false;
  }

  // Binary search: find min t such that canReach(t) is true
  // MONOTONICITY: can reach with t → can reach with any t' > t (more cells accessible)
  let lo = grid[0][0], hi = n * n - 1;
  while (lo < hi) {
    const mid = Math.floor((lo + hi) / 2);
    if (canReach(mid)) hi = mid; else lo = mid + 1;
  }
  return lo;
}
// Time: O(n² log n)  Space: O(n²)
//
// MONOTONICITY CHECK (required before applying this pattern):
// "If I can solve the problem with threshold X, can I always solve with X+1?"
// If YES → monotonic → binary search valid.
// LC 778: higher t = more cells open = easier path ✓
// LC 1631: higher max-effort = easier path ✓
//
// ⚠️ TRAP: Binary search on non-monotonic answer → wrong. Always verify first.
// ⚠️ TRAP: Using this when Dijkstra is simpler — Dijkstra is one pass, binary
// search + BFS is log(range) passes. Same complexity, but Dijkstra is cleaner.
// Use this pattern only when you CANNOT quickly formulate edge weights for Dijkstra.

15.1 Longest Increasing Path in Matrix (LC 329)

function longestIncreasingPath(matrix: number[][]): number {
  // ⭐ KEY INSIGHT: This is an IMPLICIT DAG.
  // Edge exists from (r,c) → (nr,nc) if matrix[nr][nc] > matrix[r][c].
  // Because edges only go from smaller to larger values, there are NO cycles
  // → guaranteed DAG. On a DAG, DFS + memoization = topological sort + DP.
  //
  // WHY no visited set needed:
  // The "matrix[nr][nc] > matrix[r][c]" condition prevents revisiting.
  // We can never go back to a smaller value, so no cycles possible.
  // This is the key insight interviewers look for.
  if (!matrix.length) return 0;
  const rows = matrix.length,
    cols = matrix[0].length;
  const memo: number[][] = Array.from({ length: rows }, () => new Array(cols).fill(0));

  function dfs(r: number, c: number): number {
    if (memo[r][c] !== 0) return memo[r][c];
    let max = 1;

    for (const [dr, dc] of [
      [0, 1],
      [0, -1],
      [1, 0],
      [-1, 0],
    ]) {
      const nr = r + dr,
        nc = c + dc;
      if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && matrix[nr][nc] > matrix[r][c]) {
        max = Math.max(max, 1 + dfs(nr, nc));
      }
    }
    return (memo[r][c] = max);
  }

  let result = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) result = Math.max(result, dfs(r, c));
  }
  return result;
}
// ⭐ Implicit DAG: edge from (r,c) to neighbor if neighbor > current
// DFS + memoization = topological sort + DP

15.2 Bitmask DP + BFS (LC 847 — Shortest Path Visiting All Nodes)

// State = (node, visited_bitmask). visited_bitmask bit i=1 means node i visited.
function shortestPathAllNodes(graph: number[][]): number {
  const n = graph.length;
  const fullMask = (1 << n) - 1; // All nodes visited = all bits set

  // dist[node][mask] = min steps to be at 'node' with 'mask' visited
  const dist: number[][] = Array.from({ length: n }, () => new Array(1 << n).fill(Infinity));

  const queue: [number, number, number][] = []; // [node, mask, steps]

  // Start BFS from EVERY node simultaneously (can start anywhere)
  for (let i = 0; i < n; i++) {
    dist[i][1 << i] = 0;
    queue.push([i, 1 << i, 0]);
  }

  let head = 0;
  while (head < queue.length) {
    const [node, mask, steps] = queue[head++];

    if (mask === fullMask) return steps;
    if (steps > dist[node][mask]) continue; // Stale entry

    for (const neighbor of graph[node]) {
      const newMask = mask | (1 << neighbor);
      if (steps + 1 < dist[neighbor][newMask]) {
        dist[neighbor][newMask] = steps + 1;
        queue.push([neighbor, newMask, steps + 1]);
      }
    }
  }
  return -1;
}
// Time: O(n × 2^n × n)  Space: O(n × 2^n)
//
// ⭐ BITMASK OPERATIONS CHEATSHEET:
// Check if node i visited:  mask & (1 << i)
// Mark node i as visited:   mask | (1 << i)
// Unmark node i:            mask & ~(1 << i)
// Check all visited:        mask === (1 << n) - 1
// ⚠️ Trap 1: Must start from ALL nodes simultaneously, not just node 0.
// ⚠️ Trap 2: n must be small (≤ 20). Always verify before using bitmask.

⚠️ SECTION 16: COMMON BUGS & FIXES

BUG #1: Using shift() in BFS
❌ while (queue.length > 0) node = queue.shift() // O(n) per call!
✅ while (head < queue.length) node = queue[head++] // O(1)
Impact: Turns O(V+E) into O(V^2+E) for sparse graphs

BUG #2: Marking visited on DEQUEUE
❌ node = queue.shift(); visited.add(node); // WRONG
✅ visited.add(node); queue.push(node); // RIGHT
Impact: Exponential duplicates in queue, memory limit exceeded.

BUG #3: Dijkstra without stale entry check
❌ [d, node] = heap.pop(); ... process neighbors
✅ [d, node] = heap.pop(); if (d > dist[node]) continue;
Impact: Processes the same node multiple times wastefully.

BUG #4: String key collision in grid
❌ const key = `${r}${c}` // r=1,c=23 collides with r=12,c=3!
✅ const key = `${r},${c}` // Always use separator

BUG #5: Object references in Sets (JavaScript/TypeScript specific)
❌ visited.add([r, c]); if (visited.has([r, c])) ... // ALWAYS RETURNS FALSE
✅ visited.add(`${r},${c}`); // Primitives only! Arrays are passed by reference.

BUG #6: No copy in k-stops Bellman-Ford
❌ for ([u,v,w] of edges) dist[v] = min(dist[v], dist[u] + w)
✅ nextDist = [...dist]; for (...) nextDist[v] = ...; dist = nextDist;
Impact: Bleeds multiple edge updates into a single "stop" iteration.

BUG #7: Mutating graph while iterating (Hierholzer's)
❌ for (const dest of graph.get(node)!) {
     graph.get(node)!.splice(0, 1); // Modifying while iterating
   }
✅ while ((graph.get(node)?.length ?? 0) > 0) {
     const next = graph.get(node)!.pop()!;
     dfs(next);
   }
Impact: Skips elements, infinite loops, or crashes depending on engine.

BUG #8: Dijkstra returning Infinity for unreachable nodes
❌ return dist[target]; // Returns Infinity — caller may not handle
✅ return dist[target] === Infinity ? -1 : dist[target];
Impact: Silent wrong answer. Always convert Infinity to -1 before returning.

BUG #9: Off-by-one in K-stops Bellman-Ford (the most common LC 787 bug)
❌ for (let i = 0; i < k; i++)  // k iterations = k-1 stops!
✅ for (let i = 0; i <= k; i++) // k+1 iterations = k stops
Impact: Wrong answer. This is the single most common bug on LC 787.

BUG #10: Union-Find missing self-loop check
❌ uf.union(u, v); // If u === v, find(u) === find(v) → returns false
                   // But this IS a cycle (self-loop)!
✅ if (u === v) return /* handle as cycle */;
   uf.union(u, v);
Impact: LC rarely has self-loops but interviewers ask as follow-up.
Having the answer ready = SDE3 signal.

BUG #11: Index Pointer + unshift() in 0-1 BFS (The "Index-Shifting" Trap)
❌ while (head < deque.length) { const node = deque[head++]; ... deque.unshift(neighbor); }
✅ while (deque.length > 0) { const node = deque.shift()!; ... deque.unshift(neighbor); }
Impact: unshift() physically shifts all elements right by one. A head index pointer
tracks absolute position — after unshift(), positions shift, so head points to the
wrong element. Newly inserted front elements are skipped; prior elements may reprocess.
Rule: Never mix unshift() with index-pointer traversal. Use shift() exclusively.

UNION-FIND vs DFS for Connectivity:
  UF: O(α(n)) per op. Use for DYNAMIC connectivity (edges added online).
      → "Are X and Y connected after adding edges?" → UF wins
      → LC 684, 721, 947
  DFS/BFS: O(V+E) one-time. Use for STATIC graph with full traversal.
      → "How many components?" → DFS is simpler
      → LC 200, 323
  ⚠️ TRAP: UF only for UNDIRECTED graphs. For directed cycles → use Kahn's or DFS.

RECURSIVE vs ITERATIVE DFS:
  Recursive: Cleaner, natural backtracking. Use when depth ≤ ~10K nodes.
  Iterative: Stack-safe for very deep graphs. Use when depth > 10K.
  RULE: For post-order (topo sort, Euler path), recursive is MUCH cleaner.
        Prefer recursive unless depth is explicitly a concern.

KRUSKAL's vs PRIM's for MST:
  Kruskal's: O(E log E). Edge list input, greedily pick smallest non-cycle.
       → Better for SPARSE graphs (E ≈ V). Requires UF.
       → LC 1584, 1135
  Prim's: O(E log V). Grow MST from vertex, adjacency list input.
       → Better for DENSE graphs (E ≈ V²). Requires MinHeap.
       → Conceptually similar to Dijkstra
  DEFAULT: Use Kruskal's for most LC (UF already in template).
