1. DECISION FRAMEWORK

Senior Engineer mindset: Before touching the keyboard, spend 3 minutes here. Every minute you spend framing pays back 5 minutes in coding.

├─────────────────────────────────────────────────────┤
│ ✅ Optimal substructure?                            │

│ ✅ Overlapping subproblems?                         │

│                                                     │

                          ↓

├─────────────────────────────────────────────────────┤

│                                                     │
│ Common State Axes:                                  │
│  • Index i in array/string                         │

│                                                     │

├─────────────────────────────────────────────────────┤

                          ↓

🔴 DP ANTI-PATTERNS (Mistakes That Kill Candidates — From 20 Years of Interviewing):

ANTI-PATTERN 1: Vague state definition
  ❌ "dp[i] = the answer at i"          ← meaningless, leads to wrong recurrence
  ✅ "dp[i] = max sum of subarray ENDING at index i"   ← precise, unambiguous

ANTI-PATTERN 2: Confusing "min/max" vs "count" recurrence direction
  min/max: dp[i] = f(dp[i-1], dp[i-2])    ← forward propagation, take optimal
  count:   dp[i] += dp[j] for all valid j  ← accumulate ALL valid predecessors
  ❌ Using max() on a count problem → gives 1 instead of total ways

ANTI-PATTERN 3: Using top-down recursion when depth > ~10K
  ❌ Top-down on a string of length 100K → call stack overflow
  ✅ Use bottom-up tabulation OR increase stack size explicitly
  Rule: if n > 10,000 and states are O(n), prefer bottom-up

ANTI-PATTERN 4: Forgetting MOD in count problems
  LC 62, 91, 518, 1155 all say "return answer mod 10^9 + 7"
  ❌ dp[i] = dp[i-1] + dp[i-2]          ← overflows Number.MAX_SAFE_INTEGER
  ✅ dp[i] = (dp[i-1] + dp[i-2]) % MOD
  Apply MOD on every addition, BEFORE storing back into dp[].

ANTI-PATTERN 5: Off-by-one in interval DP base cases
  ❌ for (let len = 1; ...)  → may miss len=2 base case for palindromes
  ✅ Always explicitly set dp[i][i] = base (length-1 case)
     Then handle dp[i][i+1] = base (length-2 case) before the main loop

ANTI-PATTERN 6: Space optimization when reconstruction is needed
  ❌ Rolling 1D array → cannot backtrack to find which items were chosen
  ✅ If asked "what items / what path", keep full 2D table

ANTI-PATTERN 7: Rebuilding substrings in the inner loop
  ❌ dp[j] && wordSet.has(s.slice(j, i))  ← s.slice is O(i-j) per call
  ✅ Precompute max word length; only try j >= i - maxWordLen

ANTI-PATTERN 8: Wrong loop direction in space-optimized knapsack
  ❌ 0/1 knapsack with LEFT-TO-RIGHT inner loop → item used multiple times
  ✅ 0/1 = RIGHT-TO-LEFT (prevents re-use)
     Unbounded = LEFT-TO-RIGHT (allows re-use)

4. 1D DP TEMPLATES

4.1 Classic 1D Template (Fibonacci-style)

// PATTERN: dp[i] depends on dp[i-1], dp[i-2], ...
// Examples: Climbing Stairs (LC 70), House Robber (LC 198)

function dp1D(nums: number[]): number {
  const n = nums.length;
  if (n === 0) return 0;

  // dp[i] = best answer considering first i elements
  const dp = new Array(n + 1).fill(0);
  dp[0] = 0; // base case: empty
  dp[1] = nums[0]; // base case: one element

  for (let i = 2; i <= n; i++) {
    // ── FILL RECURRENCE HERE ──
    // e.g., House Robber: take or skip
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
  }

  return dp[n];
}
// Time: O(n), Space: O(n) → can reduce to O(1) with rolling variables

// ⭐ SPACE OPTIMIZATION (when dp[i] only needs dp[i-1] and dp[i-2]):
function dp1DSpaceOpt(nums: number[]): number {
  let prev2 = 0,
    prev1 = nums[0];
  for (let i = 1; i < nums.length; i++) {
    const curr = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = curr;
  }
  return prev1;
}

4.2 Longest Increasing Subsequence (LIS) — O(n²)

// dp[i] = length of LIS ending at index i
// LC 300 — Classic, understand BOTH approaches

function lengthOfLIS_DP(nums: number[]): number {
  const n = nums.length;
  const dp = new Array(n).fill(1); // every element is LIS of length 1

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
      }
    }
  }

  return Math.max(...dp);
}
// Time: O(n²), Space: O(n)

4.2b Count of Longest Increasing Subsequences (LC 673)

// dp[i]    = length of LIS ending at index i
// count[i] = number of LIS of that length ending at index i
// LC 673 — common SDE3 follow-up to LC 300

function findNumberOfLIS(nums: number[]): number {
  const n = nums.length;
  const dp = new Array(n).fill(1);      // LIS length ending at i
  const cnt = new Array(n).fill(1);     // # of such LIS ending at i

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        if (dp[j] + 1 > dp[i]) {
          dp[i] = dp[j] + 1;            // found a longer LIS
          cnt[i] = cnt[j];              // reset count
        } else if (dp[j] + 1 === dp[i]) {
          cnt[i] += cnt[j];             // another way to reach same length
        }
      }
    }
  }

  const maxLen = Math.max(...dp);
  let total = 0;
  for (let i = 0; i < n; i++) {
    if (dp[i] === maxLen) total += cnt[i];
  }
  return total;
}
// Time: O(n²), Space: O(n)
// KEY INSIGHT: Maintain cnt[] in parallel with dp[].
//   dp[j]+1 > dp[i]  → strictly longer path found, inherit count from j
//   dp[j]+1 === dp[i] → equally long path found, accumulate count
// SDE3 SIGNAL: When asked "how many optimal solutions exist?" — always think
// about running a parallel count[] array alongside the value dp[].

4.3 LIS — O(n log n) via Binary Search (SDE3 Expected)

// PATIENCE SORTING technique — tails[i] = smallest tail of any IS of length i+1
// ⭐ SDE3 interviewers WILL ask for this optimization

function lengthOfLIS_BS(nums: number[]): number {
  const tails: number[] = []; // tails[i] = min ending val of IS with length i+1

  for (const num of nums) {
    let lo = 0,
      hi = tails.length;
    // Binary search for first tail >= num (lower_bound)
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (tails[mid] < num) lo = mid + 1;
      else hi = mid;
    }
    tails[lo] = num; // replace or extend
  }

  return tails.length;
}
// Time: O(n log n), Space: O(n)
//NOTE: tails array is NOT the actual subsequence, just a tool to find length.
// To reconstruct the actual LIS, you need parent pointers (LC 354).

4.3b DP + Binary Search (SDE3 Pattern)

WHEN TO COMBINE DP WITH BINARY SEARCH:
───────────────────────────────────────────────────────────────
1. States are sorted / monotone → binary search to find transition
2. LIS-style problems in 2D    → sort one dimension, LIS on other
3. Job scheduling               → binary search for last non-overlapping job
4. Egg drop style               → binary search on answer within dp

Russian Doll Envelopes — 2D LIS (LC 354)

// Sort: ascending width, DESCENDING height (within same width).
// Then run O(n log n) LIS on heights only.
// LC 354 — Hard. The sort trick is the entire key insight.

function maxEnvelopes(envelopes: number[][]): number {
  // ⭐ CRITICAL SORT: ascending width, descending height for same width.
  // WHY descending height for ties: prevents two envelopes with the same
  // width from both being selected in the LIS (a wider envelope can't fit
  // inside another with the same width).
  envelopes.sort((a, b) => a[0] !== b[0] ? a[0] - b[0] : b[1] - a[1]);

  // Now reduce to 1D LIS on heights
  const tails: number[] = [];
  for (const [, h] of envelopes) {
    let lo = 0, hi = tails.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (tails[mid] < h) lo = mid + 1;
      else hi = mid;
    }
    tails[lo] = h;
  }
  return tails.length;
}
// Time: O(n log n), Space: O(n)
// WITHOUT the sort trick: naive O(n²) DP with two conditions

Maximum Profit in Job Scheduling (LC 1235)

// dp[i] = max profit considering jobs[0..i-1]
// For each job, binary search for the last job that ends ≤ this job's start.
// LC 1235 — This is the canonical "DP + binary search on sorted structure" problem.

function jobScheduling(startTime: number[], endTime: number[], profit: number[]): number {
  const n = startTime.length;
  // Create job triples and sort by end time
  const jobs = startTime.map((s, i) => [s, endTime[i], profit[i]]);
  jobs.sort((a, b) => a[1] - b[1]);

  // dp[i] = max profit using jobs ending at or before jobs[i-1]
  const dp = new Array(n + 1).fill(0);

  for (let i = 1; i <= n; i++) {
    const [start, , p] = jobs[i - 1];

    // Binary search: find last job whose endTime <= this job's startTime
    let lo = 0, hi = i - 1;
    while (lo < hi) {
      const mid = (lo + hi + 1) >> 1;
      if (jobs[mid - 1][1] <= start) lo = mid;
      else hi = mid - 1;
    }
    // lo = index of last compatible job (0 = none)
    dp[i] = Math.max(dp[i - 1], dp[lo] + p);
  }
  return dp[n];
}
// Time: O(n log n), Space: O(n)
// KEY: Sort by endTime. Binary search finds "last non-overlapping job".

Super Egg Drop (LC 887) — DP + Binary Search on State

// dp[m][k] = max floors testable with m moves and k eggs
// Binary search insight: instead of dp[k][n] (TLE), flip to dp[m][k].
// LC 887 — Hard. The state flip + binary search is the SDE3 signal.

function superEggDrop(k: number, n: number): number {
  // dp[m] = max floors we can check with m moves and k eggs
  // Recurrence: with one more move and k eggs, we can check
  //   dp[m-1][k-1] floors below + 1 current + dp[m-1][k] floors above
  // = dp[m-1][k-1] + 1 + dp[m-1][k]
  // Keep incrementing moves until dp[moves][k] >= n

  let moves = 0;
  const dp = new Array(k + 1).fill(0);

  while (dp[k] < n) {
    moves++;
    // Traverse RIGHT TO LEFT to avoid using updated values
    for (let eggs = k; eggs >= 1; eggs--) {
      dp[eggs] = dp[eggs - 1] + 1 + dp[eggs];
    }
  }
  return moves;
}
// Time: O(k log n), Space: O(k)
// INSIGHT: "minimum moves to guarantee finding critical floor" = flip to
// "how many floors can I test with m moves and k eggs?" Then binary search
// on m (the answer), which is at most O(n).

4.4 Maximum Subarray (Kadane’s) — Linear DP

// dp[i] = max sum subarray ENDING at i
// LC 53, 918 (circular version)

function maxSubArray(nums: number[]): number {
  let maxSum = nums[0];
  let curr = nums[0];

  for (let i = 1; i < nums.length; i++) {
    // At each position: extend previous subarray OR start fresh
    curr = Math.max(nums[i], curr + nums[i]);
    maxSum = Math.max(maxSum, curr);
  }

  return maxSum;
}
// Time: O(n), Space: O(1)

// ⭐ TRAP: LC 918 (Maximum Sum Circular Subarray)
// Answer = max(normal Kadane, totalSum - min subarray)
// Edge case: if all numbers are negative, min subarray = whole array → return normal Kadane

4.4b Maximum Product Subarray (Min/Max Tracking)

// dp tracks BOTH max and min product ending at i.
// WHY min: a negative number flips min→max. The most-negative product can
// become the largest the moment we multiply by another negative.
// LC 152 — referenced everywhere; the two-variable trick is the whole point.

function maxProduct(nums: number[]): number {
  let result = nums[0];
  let curMax = nums[0]; // max product ending at i
  let curMin = nums[0]; // min product ending at i (could flip to max)

  for (let i = 1; i < nums.length; i++) {
    const n = nums[i];
    // ⭐ If n is negative, swap: the previous min becomes the candidate max.
    // Capture both before overwriting (curMax is used to compute curMin).
    const cand1 = curMax * n;
    const cand2 = curMin * n;
    curMax = Math.max(n, cand1, cand2); // start fresh at n, or extend
    curMin = Math.min(n, cand1, cand2);

    result = Math.max(result, curMax);
  }
  return result;
}
// Time: O(n), Space: O(1)
// ⭐ KEY INSIGHT: Kadane tracks one running value; product needs TWO because
// sign flips. Always recompute curMax/curMin from {n, max*n, min*n}.
// TRAP: don't update curMax then use the NEW curMax for curMin — snapshot first.
// SDE3 SIGNAL: "Unlike sum, product isn't monotonic under sign, so I carry the
// running minimum to capture negative-times-negative comebacks."

4.5 Word Break — 1D Boolean DP

// dp[i] = can s[0..i-1] be segmented using wordDict?
// LC 139

function wordBreak(s: string, wordDict: string[]): boolean {
  const wordSet = new Set(wordDict);
  const n = s.length;
  const dp = new Array(n + 1).fill(false);
  dp[0] = true; // empty string is always valid

  for (let i = 1; i <= n; i++) {
    for (let j = 0; j < i; j++) {
      if (dp[j] && wordSet.has(s.slice(j, i))) {
        dp[i] = true;
        break; // ⭐ Early exit once found
      }
    }
  }

  return dp[n];
}
// Time: O(n² * L) where L = avg word length for slice, Space: O(n)
// SDE3: Precompute max word length to prune inner loop: j >= i - maxLen

4.6 Decode Ways — Conditional 1D DP

// dp[i] = number of ways to decode s[0..i-1]
// LC 91 — Hard due to '0' handling

function numDecodings(s: string): number {
  const n = s.length;
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1; // empty string: 1 way

  for (let i = 1; i <= n; i++) {
    // Single digit decode: s[i-1] != '0'
    if (s[i - 1] !== "0") dp[i] += dp[i - 1];

    // Two digit decode: s[i-2..i-1] in range 10-26
    if (i >= 2) {
      const twoDigit = parseInt(s.slice(i - 2, i));
      if (twoDigit >= 10 && twoDigit <= 26) dp[i] += dp[i - 2];
    }
  }

  return dp[n];
}
// Time: O(n), Space: O(n) → reducible to O(1) with 3 variables
// TRAP: '0' cannot be decoded alone. Always check before adding dp[i-1].

4.7 DP Reconstruction — Backtracking Through the Table

THE MOST MISSED SKILL: Computing dp[n] gives the OPTIMAL VALUE.
Interviews almost always want the ACTUAL SOLUTION (path, sequence, items).
Two techniques: (1) backtrack through the filled dp table, (2) parent pointers.

LCS Reconstruction → Shortest Common Supersequence (LC 1092)

// Step 1: fill the LCS dp table (same as always)
// Step 2: backtrack from dp[m][n] to dp[0][0] to reconstruct the LCS
// Step 3: for SCS (LC 1092), interleave both strings guided by LCS

function shortestCommonSupersequence(str1: string, str2: string): string {
  const m = str1.length, n = str2.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++)
    for (let j = 1; j <= n; j++)
      dp[i][j] = str1[i-1] === str2[j-1]
        ? dp[i-1][j-1] + 1
        : Math.max(dp[i-1][j], dp[i][j-1]);

  // ⭐ BACKTRACK: start at dp[m][n], walk back to dp[0][0]
  let i = m, j = n;
  const result: string[] = [];

  while (i > 0 && j > 0) {
    if (str1[i-1] === str2[j-1]) {
      result.push(str1[i-1]); // in LCS → take once
      i--; j--;
    } else if (dp[i-1][j] > dp[i][j-1]) {
      result.push(str1[i-1]); // came from top → str1 char not in LCS
      i--;
    } else {
      result.push(str2[j-1]); // came from left → str2 char not in LCS
      j--;
    }
  }
  while (i > 0) { result.push(str1[i-1]); i--; }
  while (j > 0) { result.push(str2[j-1]); j--; }

  return result.reverse().join('');
}
// Time: O(m*n), Space: O(m*n)

LIS Reconstruction (LC 300 / LC 354 follow-up)

// Reconstruct the actual LIS, not just its length.
// Use parent[] array: parent[i] = index j that gave dp[i] its best value.

function lisReconstruct(nums: number[]): number[] {
  const n = nums.length;
  const dp = new Array(n).fill(1);
  const parent = new Array(n).fill(-1); // -1 = no predecessor

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
        dp[i] = dp[j] + 1;
        parent[i] = j; // j is the predecessor of i in the LIS
      }
    }
  }

  // Find end of LIS (index with maximum dp value)
  let endIdx = 0;
  for (let i = 1; i < n; i++) if (dp[i] > dp[endIdx]) endIdx = i;

  // Walk parent pointers backward
  const lis: number[] = [];
  for (let cur = endIdx; cur !== -1; cur = parent[cur]) {
    lis.push(nums[cur]);
  }
  return lis.reverse();
}

0/1 Knapsack Reconstruction (Which Items Were Taken?)

// After filling dp[n][W], backtrack to find which items were selected.
// Rule: if dp[i][w] !== dp[i-1][w], item i was included.

function knapsackItems(
  weights: number[], values: number[], capacity: number
): number[] {
  const n = weights.length;
  // Fill full 2D table (needed for reconstruction — can't use 1D rolling array)
  const dp: number[][] = Array.from({ length: n + 1 }, () =>
    new Array(capacity + 1).fill(0)
  );

  for (let i = 1; i <= n; i++)
    for (let w = 0; w <= capacity; w++)
      dp[i][w] = weights[i-1] <= w
        ? Math.max(dp[i-1][w], dp[i-1][w - weights[i-1]] + values[i-1])
        : dp[i-1][w];

  // ⭐ BACKTRACK from dp[n][capacity]
  const selected: number[] = [];
  let w = capacity;
  for (let i = n; i >= 1; i--) {
    if (dp[i][w] !== dp[i-1][w]) { // item i was taken
      selected.push(i - 1);        // push 0-indexed item
      w -= weights[i-1];
    }
  }
  return selected.reverse();
}
// ⚠️ TRAP: Reconstruction REQUIRES the full 2D dp table.
// Space-optimized 1D knapsack loses the information needed to backtrack.
// If reconstruction is required → always use 2D.

Edit Distance Reconstruction (What Operations Were Performed?)

// After filling dp[m][n], backtrack to list the actual edit operations.

function editDistanceOps(word1: string, word2: string): string[] {
  const m = word1.length, n = word2.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
  for (let i = 0; i <= m; i++) dp[i][0] = i;
  for (let j = 0; j <= n; j++) dp[0][j] = j;

  for (let i = 1; i <= m; i++)
    for (let j = 1; j <= n; j++)
      dp[i][j] = word1[i-1] === word2[j-1]
        ? dp[i-1][j-1]
        : 1 + Math.min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]);

  // Backtrack
  const ops: string[] = [];
  let i = m, j = n;
  while (i > 0 || j > 0) {
    if (i > 0 && j > 0 && word1[i-1] === word2[j-1]) {
      i--; j--; // match: no op
    } else if (j > 0 && (i === 0 || dp[i][j-1] <= dp[i-1][j] && dp[i][j-1] <= dp[i-1][j-1])) {
      ops.push(`insert '${word2[j-1]}' at pos${i}`); j--;
    } else if (i > 0 && (j === 0 || dp[i-1][j] <= dp[i][j-1] && dp[i-1][j] <= dp[i-1][j-1])) {
      ops.push(`delete '${word1[i-1]}' at pos${i-1}`); i--;
    } else {
      ops.push(`replace '${word1[i-1]}' → '${word2[j-1]}' at pos${i-1}`); i--; j--;
    }
  }
  return ops.reverse();
}

4.8 Partition DP — Split Array into K Groups

PATTERN: dp[i][k] = best cost to partition arr[0..i-1] into k groups.
Different from knapsack: here every element must be assigned exactly once.
KEY RECURRENCE: dp[i][k] = min over j<i of (dp[j][k-1] + cost(j, i))
// LC 410 — Split Array Largest Sum (partition into k parts, minimize max sum)
// dp[i][j] = min possible maximum sum when splitting nums[0..i-1] into j parts

function splitArray(nums: number[], k: number): number {
  const n = nums.length;
  const prefix = new Array(n + 1).fill(0);
  for (let i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

  // dp[i][j] = min largest-sum splitting nums[0..i-1] into j groups
  const dp: number[][] = Array.from({ length: n + 1 }, () =>
    new Array(k + 1).fill(Infinity)
  );
  dp[0][0] = 0;

  for (let j = 1; j <= k; j++) {
    for (let i = j; i <= n; i++) {
      // Last group is nums[m..i-1], previous groups cover nums[0..m-1]
      for (let m = j - 1; m < i; m++) {
        const lastGroupSum = prefix[i] - prefix[m];
        dp[i][j] = Math.min(dp[i][j], Math.max(dp[m][j - 1], lastGroupSum));
      }
    }
  }
  return dp[n][k];
}
// Time: O(n²k), Space: O(nk)
// ⭐ ALTERNATIVE: Binary search on answer + greedy feasibility check → O(n log(sum))
// For interviews: mention both, implement the one that's easier to explain.

// LC 1043 — Partition Array for Maximum Sum (LC variant)
// After partition, each element in a subarray becomes the subarray max.
// dp[i] = max sum for nums[0..i-1]
// Recurrence: for last group of length len (1..k), all become max of that group

function maxSumAfterPartitioning(arr: number[], k: number): number {
  const n = arr.length;
  const dp = new Array(n + 1).fill(0);

  for (let i = 1; i <= n; i++) {
    let maxVal = 0;
    // Try all possible last group lengths
    for (let len = 1; len <= k && i - len >= 0; len++) {
      maxVal = Math.max(maxVal, arr[i - len]);
      dp[i] = Math.max(dp[i], dp[i - len] + maxVal * len);
    }
  }
  return dp[n];
}
// Time: O(n*k), Space: O(n)
// INSIGHT: Fixing the group endpoint at i, try all lengths 1..k.
// maxVal tracks the running max within the current window.

4.9 Matrix Exponentiation DP — O(log N) for Huge N

WHEN TO USE: A linear recurrence (Fibonacci-style) where N is HUGE (up to 10^18).
Normal O(N) DP is too slow. Express the transition as a matrix; raise it to the
N-th power in O(k³ log N) where k = number of terms in the recurrence.

RECURRENCE → MATRIX MAPPING:
  Fibonacci  f(n) = f(n-1) + f(n-2)
  | f(n)   |   | 1 1 | ^(n-1)   | f(1) |
  | f(n-1) | = | 1 0 |       ·  | f(0) |
  The transition matrix's top row = the recurrence coefficients.
// 2x2 (general k×k) matrix exponentiation for linear recurrences.
// LC 70 (huge N), LC 509, LC 1137 (Tribonacci → 3×3), LC 790 (Domino → 2×2 with MOD)

const MOD = 1_000_000_007n;

function matMul(A: bigint[][], B: bigint[][]): bigint[][] {
  const n = A.length, m = B[0].length, p = B.length;
  const C: bigint[][] = Array.from({ length: n }, () => new Array(m).fill(0n));
  for (let i = 0; i < n; i++)
    for (let k = 0; k < p; k++) {
      if (A[i][k] === 0n) continue;
      for (let j = 0; j < m; j++)
        C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
    }
  return C;
}

function matPow(M: bigint[][], power: bigint): bigint[][] {
  const n = M.length;
  // Identity matrix
  let result: bigint[][] = Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => (i === j ? 1n : 0n))
  );
  let base = M;
  while (power > 0n) {
    if (power & 1n) result = matMul(result, base); // binary exponentiation
    base = matMul(base, base);
    power >>= 1n;
  }
  return result;
}

// Fibonacci in O(log N): f(0)=0, f(1)=1
function fibFast(N: number): bigint {
  if (N === 0) return 0n;
  const T = [[1n, 1n], [1n, 0n]];           // transition matrix
  const R = matPow(T, BigInt(N - 1));        // T^(N-1)
  // [f(N), f(N-1)]^T = T^(N-1) · [f(1), f(0)]^T = T^(N-1) · [1, 0]^T
  return R[0][0];                            // = f(N)
}
// Time: O(k³ log N), Space: O(k²)  where k = recurrence order (2 for Fib)
// ⭐ KEY INSIGHT: ANY linear recurrence f(n)=Σ cᵢ·f(n-i) becomes matrix power.
//   Build the companion matrix: top row = [c1, c2, ..., ck], sub-diagonal = 1s.
// SDE3 SIGNAL: "N is up to 10^18, so O(N) DP won't fit. Since the recurrence is
//   linear, I'll use matrix exponentiation for O(log N)." Most candidates miss this.
// TRAP: use BigInt + MOD; regular numbers overflow long before N gets large.

5.1 Longest Common Subsequence (LCS)

// dp[i][j] = LCS of s1[0..i-1] and s2[0..j-1]
// LC 1143 — Foundation for many other problems

function longestCommonSubsequence(text1: string, text2: string): number {
  const m = text1.length,
    n = text2.length;
  // ⭐ Allocate (m+1) x (n+1) for clean base cases
  const dp: number[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(0),
  );

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1; // characters match: extend
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]); // skip one char
      }
    }
  }

  return dp[m][n];
}
// Time: O(m*n), Space: O(m*n) → reducible to O(min(m,n)) with rolling row

// ⭐ LCS Space Optimization (two-row rolling):
function lcsSpaceOpt(text1: string, text2: string): number {
  const m = text1.length,
    n = text2.length;
  let prev = new Array(n + 1).fill(0);
  let curr = new Array(n + 1).fill(0);

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) curr[j] = prev[j - 1] + 1;
      else curr[j] = Math.max(prev[j], curr[j - 1]);
    }
    [prev, curr] = [curr, prev]; // swap references
    curr.fill(0);
  }

  return prev[n];
}

5.2 Edit Distance (Levenshtein)

// dp[i][j] = min ops to convert word1[0..i-1] to word2[0..j-1]
// LC 72 — Three operations: insert, delete, replace

function minDistance(word1: string, word2: string): number {
  const m = word1.length,
    n = word2.length;
  const dp: number[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(0),
  );

  // Base cases: converting to/from empty string
  for (let i = 0; i <= m; i++) dp[i][0] = i; // delete all
  for (let j = 0; j <= n; j++) dp[0][j] = j; // insert all

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1]; // no op needed
      } else {
        dp[i][j] =
          1 +
          Math.min(
            dp[i - 1][j], // delete from word1
            dp[i][j - 1], // insert into word1
            dp[i - 1][j - 1], // replace
          );
      }
    }
  }

  return dp[m][n];
}
// Time: O(m*n), Space: O(m*n)

5.3 Unique Paths (Grid DP)

// dp[i][j] = number of unique paths to reach (i,j) from (0,0)
// LC 62, 63 (with obstacles)

function uniquePaths(m: number, n: number): number {
  const dp: number[][] = Array.from({ length: m }, () => new Array(n).fill(1));
  // First row and column are all 1 (only one way to move along an edge)

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[i][j] = dp[i - 1][j] + dp[i][j - 1]; // from top + from left
    }
  }

  return dp[m - 1][n - 1];
}

// LC 63 — With obstacles:
function uniquePathsWithObstacles(grid: number[][]): number {
  const m = grid.length,
    n = grid[0].length;
  if (grid[0][0] === 1 || grid[m - 1][n - 1] === 1) return 0;

  const dp: number[][] = Array.from({ length: m }, () => new Array(n).fill(0));
  dp[0][0] = 1;

  // Fill first row
  for (let j = 1; j < n; j++) dp[0][j] = grid[0][j] === 1 ? 0 : dp[0][j - 1];
  // Fill first col
  for (let i = 1; i < m; i++) dp[i][0] = grid[i][0] === 1 ? 0 : dp[i - 1][0];

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[i][j] = grid[i][j] === 1 ? 0 : dp[i - 1][j] + dp[i][j - 1];
    }
  }

  return dp[m - 1][n - 1];
}

5.4 Distinct Subsequences

// dp[i][j] = # of times s[0..j-1] appears as subseq in t[0..i-1]
// LC 115 — Tricky recurrence

function numDistinct(s: string, t: string): number {
  const m = s.length,
    n = t.length;
  // dp[i][j]: ways to form t[0..j-1] from s[0..i-1]
  const dp: number[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(0),
  );

  // Empty t can always be formed (by taking 0 chars)
  for (let i = 0; i <= m; i++) dp[i][0] = 1;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] = dp[i - 1][j]; // always: skip s[i-1]
      if (s[i - 1] === t[j - 1]) {
        dp[i][j] += dp[i - 1][j - 1]; // use s[i-1] to match t[j-1]
      }
    }
  }

  return dp[m][n];
}
// Time: O(m*n), Space: O(m*n)
// TRAP: Initialize dp[i][0] = 1 for all i. Never dp[0][j>0] = 1.

5.5 Maximal Square (2D DP on Grid)

// dp[i][j] = side length of largest all-1 square with bottom-right corner at (i,j)
// LC 221 — Beautiful DP insight

function maximalSquare(matrix: string[][]): number {
  const m = matrix.length,
    n = matrix[0].length;
  const dp: number[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(0),
  );
  let maxSide = 0;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (matrix[i - 1][j - 1] === "1") {
        // Bottleneck = smallest of the three neighbors
        dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1;
        maxSide = Math.max(maxSide, dp[i][j]);
      }
    }
  }

  return maxSide * maxSide; // area = side²
}
// Time: O(m*n), Space: O(m*n)
// ⭐ The recurrence min(top, left, top-left) + 1 is the key insight.
// Visualize: you can only extend a square if all three neighbors are squares.

5.6 DP + Monotonic Stack — O(n) Optimization

WHEN TO COMBINE DP WITH MONOTONIC STACK:
• DP recurrence is dp[i] = dp[j] + cost where j < i and cost depends on a
  "nearest smaller / larger" element → stack finds that j in O(1) amortized.
• "For each element, find the nearest smaller element to the left/right" — classic stack signal.
• Results in O(n²) → O(n) optimization over naive DP.

Sum of Subarray Minimums (LC 907)

// For each element arr[i], count how many subarrays have arr[i] as minimum.
// Contribution = arr[i] * (left_count) * (right_count)
// Monotonic stack finds nearest smaller element on left and right in O(n).

function sumSubarrayMins(arr: number[]): number {
  const MOD = 1_000_000_007n;
  const n = arr.length;
  const left = new Array(n);   // left[i] = distance to nearest smaller on left
  const right = new Array(n);  // right[i] = distance to nearest smaller on right
  const stack: number[] = [];

  // Left pass: nearest strictly smaller to the left
  for (let i = 0; i < n; i++) {
    while (stack.length && arr[stack[stack.length - 1]] >= arr[i]) stack.pop();
    left[i] = stack.length === 0 ? i + 1 : i - stack[stack.length - 1];
    stack.push(i);
  }

  stack.length = 0;

  // Right pass: nearest smaller or equal to the right (use >= vs > to avoid double-counting)
  for (let i = n - 1; i >= 0; i--) {
    while (stack.length && arr[stack[stack.length - 1]] > arr[i]) stack.pop();
    right[i] = stack.length === 0 ? n - i : stack[stack.length - 1] - i;
    stack.push(i);
  }

  let ans = 0n;
  for (let i = 0; i < n; i++) {
    ans = (ans + BigInt(arr[i]) * BigInt(left[i]) * BigInt(right[i])) % MOD;
  }
  return Number(ans);
}
// Time: O(n), Space: O(n)
// ⭐ KEY: left[i] * right[i] = number of subarrays where arr[i] is the minimum.
// Use BigInt for the multiplication to avoid overflow.

Min Cost Tree From Leaf Values (LC 1130)

// dp[i][j] = min sum of non-leaf nodes for arr[i..j]
// Naive interval DP: O(n³). Monotonic stack insight: O(n).
// INSIGHT: Remove the smaller of each adjacent pair, cost = pair product.
// Greedy with monotonic stack simulates "always remove smallest leaf first".

function mctFromLeafValues(arr: number[]): number {
  let result = 0;
  const stack: number[] = [Infinity]; // monotonic decreasing stack

  for (const val of arr) {
    while (stack[stack.length - 1] <= val) {
      const mid = stack.pop()!;
      // mid is the smallest leaf adjacent to both stack.top and val
      result += mid * Math.min(stack[stack.length - 1], val);
    }
    stack.push(val);
  }

  // Remaining elements in stack must be multiplied pairwise
  while (stack.length > 2) {
    result += stack.pop()! * stack[stack.length - 1];
  }

  return result;
}
// Time: O(n), Space: O(n)
// Equivalent to O(n³) interval DP but uses the greedy observation that
// the minimum element should always be paired with the smaller of its neighbors.

6. INTERVAL DP TEMPLATES

Mentor note: Interval DP is the hardest flavor to recognize. The giveaway is: “operate on a subarray/substring and combine two pieces”. Always think about what happens LAST (the last balloon popped, the last palindrome palindrome cut, etc.).

6.1 Burst Balloons (Interval DP Classic)

// dp[i][j] = max coins from bursting ALL balloons between i and j (exclusive)
// LC 312 — Think "what is the LAST balloon to burst?"

function maxCoins(nums: number[]): number {
  // Add sentinel balloons at boundaries (value 1)
  const arr = [1, ...nums, 1];
  const n = arr.length;
  // dp[i][j] = max coins from open interval (i, j), bursting all inside
  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  // Fill by increasing length of interval
  for (let len = 2; len < n; len++) {
    // len = gap between endpoints
    for (let i = 0; i + len < n; i++) {
      const j = i + len;
      for (let k = i + 1; k < j; k++) {
        // k = LAST balloon to burst in (i,j)
        dp[i][j] = Math.max(
          dp[i][j],
          arr[i] * arr[k] * arr[j] + dp[i][k] + dp[k][j],
        );
      }
    }
  }

  return dp[0][n - 1];
}
// Time: O(n³), Space: O(n²)
// KEY INSIGHT: By choosing k as the LAST to burst (not first), i and j are
// still present when k bursts, making arr[i]*arr[k]*arr[j] correct.

6.2 Minimum Cost to Merge Stones / Interval Cut

// dp[i][j] = min cost to reduce stones[i..j] to 1 pile
// LC 1000 — Generalized merging

function mergeStones(stones: number[], k: number): number {
  const n = stones.length;
  // Cannot reduce to 1 pile if (n-1) % (k-1) != 0
  if ((n - 1) % (k - 1) !== 0) return -1;

  // Prefix sums for range sum queries
  const prefix = new Array(n + 1).fill(0);
  for (let i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];

  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let len = k; len <= n; len++) {
    for (let i = 0; i + len - 1 < n; i++) {
      const j = i + len - 1;
      dp[i][j] = Infinity;
      // Try all split points: step size k-1 ensures valid merges
      for (let m = i; m < j; m += k - 1) {
        dp[i][j] = Math.min(dp[i][j], dp[i][m] + dp[m + 1][j]);
      }
      // If this range can be merged into exactly 1 pile, add range cost
      if ((len - 1) % (k - 1) === 0) {
        dp[i][j] += prefix[j + 1] - prefix[i];
      }
    }
  }

  return dp[0][n - 1];
}
// Time: O(n³/k), Space: O(n²)

6.3 Longest Palindromic Subsequence

// dp[i][j] = length of LPS in s[i..j]
// LC 516

function longestPalindromeSubseq(s: string): number {
  const n = s.length;
  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  // Base case: single characters are palindromes of length 1
  for (let i = 0; i < n; i++) dp[i][i] = 1;

  // Fill for increasing lengths
  for (let len = 2; len <= n; len++) {
    for (let i = 0; i <= n - len; i++) {
      const j = i + len - 1;
      if (s[i] === s[j]) {
        dp[i][j] = (len === 2 ? 0 : dp[i + 1][j - 1]) + 2;
      } else {
        dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
      }
    }
  }

  return dp[0][n - 1];
}
// Time: O(n²), Space: O(n²)
// RELATIONSHIP: LPS(s) = LCS(s, reverse(s))
// For min insertions to make palindrome: n - LPS(s)  (LC 1312)

6.4 Palindrome Partitioning II — Min Cuts

// cuts[i] = min cuts for s[0..i]
// LC 132 — Combine palindrome check with 1D DP

function minCut(s: string): number {
  const n = s.length;
  // Precompute isPalin[i][j] using DP (expand around center)
  const isPalin: boolean[][] = Array.from({ length: n }, () =>
    new Array(n).fill(false),
  );
  for (let i = n - 1; i >= 0; i--) {
    for (let j = i; j < n; j++) {
      isPalin[i][j] = s[i] === s[j] && (j - i <= 2 || isPalin[i + 1][j - 1]);
    }
  }

  // cuts[i] = min cuts for s[0..i]
  const cuts = new Array(n).fill(0);
  for (let i = 0; i < n; i++) {
    if (isPalin[0][i]) {
      cuts[i] = 0;
      continue;
    } // whole prefix is palindrome
    cuts[i] = i; // worst case: cut after every character
    for (let j = 1; j <= i; j++) {
      if (isPalin[j][i]) {
        cuts[i] = Math.min(cuts[i], cuts[j - 1] + 1);
      }
    }
  }

  return cuts[n - 1];
}
// Time: O(n²), Space: O(n²) for isPalin precomputation

6.5 Two-Agent 3D Grid DP — Cherry Pickup II (LC 1463)

PATTERN: Two agents moving simultaneously through the same grid.
State = (row, col1, col2). Both agents always at the same row → only 3 dims.
KEY TRICK: Move both agents in the same step. row advances together.
Recurrence: dp[r][c1][c2] = grid[r][c1] + (c1≠c2 ? grid[r][c2] : 0)
                            + max over 9 combinations of (dc1, dc2) ∈ {-1,0,1}²
// LC 1463 — Cherry Pickup II
// Two robots start at row 0, col 0 and col (n-1). Move to row (rows-1).
// Each step: robot can move diagonally or straight down.
// Collect cherries; if both on same cell, count only once.

function cherryPickup(grid: number[][]): number {
  const rows = grid.length, cols = grid[0].length;

  // dp[c1][c2] = max cherries when robot1 at col c1, robot2 at col c2 (same row)
  // Use two rolling 2D arrays instead of full 3D for space efficiency
  let dp: number[][] = Array.from({ length: cols }, () => new Array(cols).fill(-1));

  // Base case: row 0
  dp[0][cols - 1] = grid[0][0] + grid[0][cols - 1];

  for (let r = 1; r < rows; r++) {
    const newDp: number[][] = Array.from({ length: cols }, () => new Array(cols).fill(-1));

    for (let c1 = 0; c1 < cols; c1++) {
      for (let c2 = c1; c2 < cols; c2++) { // c2 >= c1 by symmetry (robot2 starts right)
        if (dp[c1][c2] === -1) continue; // invalid state

        // Try all 9 combinations of moves (3 choices each robot)
        for (let dc1 = -1; dc1 <= 1; dc1++) {
          for (let dc2 = -1; dc2 <= 1; dc2++) {
            const nc1 = c1 + dc1, nc2 = c2 + dc2;
            if (nc1 < 0 || nc1 >= cols || nc2 < 0 || nc2 >= cols) continue;
            if (nc1 > nc2) continue; // maintain nc1 <= nc2

            const cherries = dp[c1][c2]
              + grid[r][nc1]
              + (nc1 !== nc2 ? grid[r][nc2] : 0); // don't double-count

            newDp[nc1][nc2] = Math.max(newDp[nc1][nc2], cherries);
          }
        }
      }
    }
    dp = newDp;
  }

  // Answer = max over all column pairs at the last row
  let ans = 0;
  for (let c1 = 0; c1 < cols; c1++)
    for (let c2 = c1; c2 < cols; c2++)
      ans = Math.max(ans, dp[c1][c2]);
  return Math.max(ans, 0);
}
// Time: O(rows × cols² × 9) = O(rows × cols²), Space: O(cols²)
// ⭐ OPTIMIZATIONS USED:
//   1. c2 >= c1 symmetry halves the state space
//   2. Rolling 2D arrays (not full 3D) → O(cols²) space instead of O(rows×cols²)
//   3. Skip dp[c1][c2] === -1 (invalid / unreachable states)
//
// GENERAL TWO-AGENT DP TEMPLATE:
//   • State: (step, agent1_pos, agent2_pos)
//   • If agents move in sync: step dimension can be rolled away
//   • Use symmetry (agent1_pos ≤ agent2_pos) to halve states
//   • Don't double-count when both agents are on the same cell

7.1 Regex / Wildcard Matching

// dp[i][j] = does p[0..j-1] match s[0..i-1]?
// LC 10 (regex: . and *) — The hardest string DP

function isMatch_regex(s: string, p: string): boolean {
  const m = s.length,
    n = p.length;
  const dp: boolean[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(false),
  );
  dp[0][0] = true;

  // Handle patterns like a*, a*b*, a*b*c* matching empty string
  for (let j = 2; j <= n; j++) {
    if (p[j - 1] === "*") dp[0][j] = dp[0][j - 2];
  }

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (p[j - 1] === "*") {
        // '*' matches zero of preceding char: dp[i][j-2]
        // '*' matches one more: dp[i-1][j] if p[j-2] matches s[i-1]
        dp[i][j] =
          dp[i][j - 2] ||
          (dp[i - 1][j] && (p[j - 2] === "." || p[j - 2] === s[i - 1]));
      } else if (p[j - 1] === "." || p[j - 1] === s[i - 1]) {
        dp[i][j] = dp[i - 1][j - 1]; // direct match
      }
    }
  }

  return dp[m][n];
}
// Time: O(m*n), Space: O(m*n)

7.2 Interleaving String

// dp[i][j] = can s3[0..i+j-1] be formed by interleaving s1[0..i-1] and s2[0..j-1]?
// LC 97

function isInterleave(s1: string, s2: string, s3: string): boolean {
  const m = s1.length,
    n = s2.length;
  if (m + n !== s3.length) return false;

  const dp: boolean[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(false),
  );
  dp[0][0] = true;

  for (let i = 1; i <= m; i++)
    dp[i][0] = dp[i - 1][0] && s1[i - 1] === s3[i - 1];
  for (let j = 1; j <= n; j++)
    dp[0][j] = dp[0][j - 1] && s2[j - 1] === s3[j - 1];

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] =
        (dp[i - 1][j] && s1[i - 1] === s3[i + j - 1]) ||
        (dp[i][j - 1] && s2[j - 1] === s3[i + j - 1]);
    }
  }

  return dp[m][n];
}

8. KNAPSACK FAMILY TEMPLATES

The knapsack is the most disguised DP. “Partition into equal subset”, “target sum”, “coin change”—they’re all knapsack under the hood. Learn to see through the disguise.

8.1 0/1 Knapsack — Classic

// Each item used at most once. Maximize value subject to weight capacity.
// Foundation for LC 416, 494, 1049

function knapsack01(
  weights: number[],
  values: number[],
  capacity: number,
): number {
  const n = weights.length;
  // dp[w] = max value using capacity w
  const dp = new Array(capacity + 1).fill(0);

  for (let i = 0; i < n; i++) {
    // ⭐ CRITICAL: Traverse RIGHT TO LEFT to avoid using item i twice
    for (let w = capacity; w >= weights[i]; w--) {
      dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
    }
  }

  return dp[capacity];
}
// Time: O(n * capacity), Space: O(capacity)
// WHY RIGHT TO LEFT: If we go left-to-right, dp[w - weights[i]] might already
// reflect item i being used, causing it to be used multiple times.

8.2 0/1 Knapsack — Boolean Variant (Partition Equal Subset Sum)

// dp[w] = can we achieve sum w using a subset?
// LC 416

function canPartition(nums: number[]): boolean {
  const total = nums.reduce((a, b) => a + b, 0);
  if (total % 2 !== 0) return false;
  const target = total / 2;

  const dp = new Array(target + 1).fill(false);
  dp[0] = true; // empty subset sums to 0

  for (const num of nums) {
    for (let w = target; w >= num; w--) {
      // Right to left!
      dp[w] = dp[w] || dp[w - num];
    }
  }

  return dp[target];
}
// Time: O(n * target), Space: O(target)

8.3 0/1 Knapsack — Count Variant (Target Sum)

// Count # subsets that sum to target
// LC 494 (with +/- signs)

function findTargetSumWays(nums: number[], target: number): number {
  // Let P = set of positives, N = set of negatives
  // P - N = target, P + N = total → P = (total + target) / 2
  // Count subsets summing to (total + target) / 2
  const total = nums.reduce((a, b) => a + b, 0);
  if ((total + target) % 2 !== 0 || Math.abs(target) > total) return 0;
  const sum = (total + target) / 2;

  const dp = new Array(sum + 1).fill(0);
  dp[0] = 1; // one way to reach sum 0: take nothing

  for (const num of nums) {
    for (let w = sum; w >= num; w--) {
      // Right to left!
      dp[w] += dp[w - num];
    }
  }

  return dp[sum];
}
// Time: O(n * sum), Space: O(sum)
// ⭐ TRANSFORMATION TRICK: Convert +/- problem to subset sum by algebra.

8.4 Unbounded Knapsack — Coin Change (Min Coins)

// Each coin can be used unlimited times. Minimize # coins.
// LC 322

function coinChange(coins: number[], amount: number): number {
  const dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;

  for (let w = 1; w <= amount; w++) {
    for (const coin of coins) {
      if (coin <= w && dp[w - coin] !== Infinity) {
        dp[w] = Math.min(dp[w], dp[w - coin] + 1);
      }
    }
  }

  return dp[amount] === Infinity ? -1 : dp[amount];
}
// Time: O(amount * #coins), Space: O(amount)
// ⭐ UNBOUNDED: Traverse LEFT TO RIGHT (item can be reused)
// vs 0/1 Knapsack: RIGHT TO LEFT (each item once)

8.5 Unbounded Knapsack — Coin Change II (Count Ways)

// Count # ways to make amount using coins (unlimited each). Order doesn't matter.
// LC 518

function change(amount: number, coins: number[]): number {
  const dp = new Array(amount + 1).fill(0);
  dp[0] = 1;

  // ⭐ OUTER LOOP = coins, INNER LOOP = amounts
  // This ensures combinations (not permutations) — each coin subset counted once
  for (const coin of coins) {
    for (let w = coin; w <= amount; w++) {
      dp[w] += dp[w - coin];
    }
  }

  return dp[amount];
}
// Time: O(amount * #coins), Space: O(amount)

// COMPARISON:
// Outer=coins, Inner=amounts → COMBINATIONS (each subset once)    ← Coin Change II
// Outer=amounts, Inner=coins → PERMUTATIONS (order matters)       ← Climbing Stairs style

8.6 Multi-Dimension Knapsack

// Two constraints: weight AND count
// LC 474 (Ones and Zeroes) — 2D knapsack

function findMaxForm(strs: string[], m: number, n: number): number {
  // dp[i][j] = max # strings using at most i zeros and j ones
  const dp: number[][] = Array.from({ length: m + 1 }, () =>
    new Array(n + 1).fill(0),
  );

  for (const s of strs) {
    const zeros = s.split("").filter((c) => c === "0").length;
    const ones = s.length - zeros;

    // ⭐ Traverse RIGHT TO LEFT in BOTH dimensions for 0/1 knapsack
    for (let i = m; i >= zeros; i--) {
      for (let j = n; j >= ones; j--) {
        dp[i][j] = Math.max(dp[i][j], dp[i - zeros][j - ones] + 1);
      }
    }
  }

  return dp[m][n];
}
// Time: O(L * m * n) where L = number of strings, Space: O(m*n)

8.7 Bounded Knapsack — Binary Splitting

THE THIRD KNAPSACK: each item has a LIMITED count cᵢ (not 1, not infinite).
Naive: loop the count → O(n · W · maxCount). Too slow when counts are large.

BINARY SPLITTING TRICK: any count c can be represented as powers of 2
(1, 2, 4, ..., plus a remainder). Split item with count c into ~log(c) "virtual
items" of sizes {1,2,4,...,rem}. Each virtual item is now 0/1 → run 0/1 knapsack.
WHY it works: every quantity 0..c is reachable by choosing a subset of these powers.
  e.g. c=13 → {1,2,4,6} (1+2+4=7, remainder 6). Any 0..13 = a subset sum.
// Maximize value; item i has weight w[i], value v[i], available count[i] times.
function boundedKnapsack(
  weights: number[], values: number[], counts: number[], capacity: number
): number {
  // Step 1: expand each (w, v, count) into binary-split virtual 0/1 items
  const W: number[] = [], V: number[] = [];
  for (let i = 0; i < weights.length; i++) {
    let c = counts[i];
    let k = 1;
    while (c > 0) {
      const take = Math.min(k, c);   // bundle of 'take' copies
      W.push(weights[i] * take);
      V.push(values[i] * take);
      c -= take;
      k <<= 1;                       // 1, 2, 4, 8, ... then remainder
    }
  }

  // Step 2: standard 0/1 knapsack on the expanded items (RIGHT TO LEFT)
  const dp = new Array(capacity + 1).fill(0);
  for (let i = 0; i < W.length; i++) {
    for (let cap = capacity; cap >= W[i]; cap--) {
      dp[cap] = Math.max(dp[cap], dp[cap - W[i]] + V[i]);
    }
  }
  return dp[capacity];
}
// Time: O(W · Σ log(countᵢ)), Space: O(W)
// ⭐ KEY INSIGHT: Bounded → 0/1 via binary decomposition. Turns an O(count)
//   inner factor into O(log count). This is THE canonical bounded-knapsack trick.
// SDE3 SIGNAL: "Counts are large, so instead of looping each copy I'll binary-split
//   each item into log(count) bundles and run plain 0/1 knapsack."

9.1 Stock Machine — 1 Transaction (LC 121)

// States: not_holding → holding → sold (done)
function maxProfit_1tx(prices: number[]): number {
  let minPrice = Infinity;
  let maxProfit = 0;

  for (const price of prices) {
    minPrice = Math.min(minPrice, price);
    maxProfit = Math.max(maxProfit, price - minPrice);
  }

  return maxProfit;
}
// This is O(n) greedy. Underlying DP: dp[i][0/1] — same result.

9.2 Stock Machine — Unlimited Transactions (LC 122)

function maxProfit_unlimited(prices: number[]): number {
  let profit = 0;
  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
  }
  return profit;
}
// Greedy: capture every upward movement

9.3 Stock Machine — With Cooldown (LC 309)

// States: holding, sold (cooldown), rest
// dp_hold[i] = max profit on day i if holding stock
// dp_sold[i] = max profit on day i if just sold (can't buy tomorrow)
// dp_rest[i] = max profit on day i if resting (can buy tomorrow)

function maxProfit_cooldown(prices: number[]): number {
  let hold = -Infinity,
    sold = 0,
    rest = 0;

  for (const price of prices) {
    const prevHold = hold,
      prevSold = sold,
      prevRest = rest;

    hold = Math.max(prevHold, prevRest - price); // keep holding OR buy from rest
    sold = prevHold + price; // sell what we held
    rest = Math.max(prevRest, prevSold); // stay resting OR come off cooldown
  }

  return Math.max(sold, rest);
}
// Time: O(n), Space: O(1)

9.4 Stock Machine — With Transaction Fee (LC 714)

function maxProfit_fee(prices: number[], fee: number): number {
  let hold = -prices[0]; // bought on day 0
  let cash = 0; // not holding

  for (let i = 1; i < prices.length; i++) {
    hold = Math.max(hold, cash - prices[i]); // keep or buy
    cash = Math.max(cash, hold + prices[i] - fee); // keep or sell (minus fee)
  }

  return cash;
}
// Time: O(n), Space: O(1)

9.5 Stock Machine — At Most K Transactions (LC 188)

// dp[k][0/1] = max profit with at most k transactions, not holding / holding
// ⭐ SDE3 PROBLEM — requires correct state transitions

function maxProfit_kTransactions(k: number, prices: number[]): number {
  const n = prices.length;
  // If k >= n/2, unlimited transactions (edge case optimization)
  if (k >= Math.floor(n / 2)) {
    let profit = 0;
    for (let i = 1; i < n; i++)
      profit += Math.max(0, prices[i] - prices[i - 1]);
    return profit;
  }

  // hold[j] = max profit with j transactions started, currently holding
  // cash[j] = max profit with j transactions completed, not holding
  const hold = new Array(k + 1).fill(-Infinity);
  const cash = new Array(k + 1).fill(0);

  for (const price of prices) {
    for (let j = k; j >= 1; j--) {
      cash[j] = Math.max(cash[j], hold[j] + price); // sell
      hold[j] = Math.max(hold[j], cash[j - 1] - price); // buy
    }
  }

  return cash[k];
}
// Time: O(n * k), Space: O(k)

9.6 Game Theory / Minimax DP (Stone Game Family)

PATTERN: Two players take turns optimally.
State: dp[i][j] = maximum ADVANTAGE (score_current - score_opponent) the CURRENT
       player can achieve from stones/piles[i..j].
Key insight: "current player" changes with each recursive call — dp[i][j] always
represents the current player's best possible lead.

RECURRENCE (for symmetric "take from ends" games):
  Take left:  piles[i] - dp[i+1][j]   ← current takes piles[i], opponent now leads
  Take right: piles[j] - dp[i][j-1]   ← current takes piles[j], opponent now leads
  dp[i][j] = max(take left, take right)
// LC 877 — Stone Game (can current player always win?)
// LC 486 — Predict the Winner (same recurrence, different framing)

function predictTheWinner(nums: number[]): boolean {
  const n = nums.length;
  // dp[i][j] = max score advantage current player can achieve over opponent
  // from nums[i..j]
  const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

  // Base case: single element, current player takes it all
  for (let i = 0; i < n; i++) dp[i][i] = nums[i];

  for (let len = 2; len <= n; len++) {
    for (let i = 0; i <= n - len; i++) {
      const j = i + len - 1;
      // Take left: gain nums[i], opponent plays optimally on [i+1..j]
      // Take right: gain nums[j], opponent plays optimally on [i..j-1]
      dp[i][j] = Math.max(
        nums[i] - dp[i + 1][j],   // take left, opponent's lead becomes our deficit
        nums[j] - dp[i][j - 1]    // take right
      );
    }
  }
  // Current player wins if their advantage >= 0
  return dp[0][n - 1] >= 0;
}
// Time: O(n²), Space: O(n²) → reducible to O(n) with rolling row

// Stone Game II (LC 1140) — Take 1 to 2M piles, M updates each turn
function stoneGameII(piles: number[]): number {
  const n = piles.length;
  // suffix[i] = sum of piles[i..n-1]
  const suffix = new Array(n + 1).fill(0);
  for (let i = n - 1; i >= 0; i--) suffix[i] = suffix[i + 1] + piles[i];

  // dp[i][m] = max stones current player can get from piles[i..] with M=m
  const dp: number[][] = Array.from({ length: n + 1 }, () =>
    new Array(n + 1).fill(0)
  );

  for (let i = n - 1; i >= 0; i--) {
    for (let m = 1; m <= n; m++) {
      for (let x = 1; x <= 2 * m && i + x <= n; x++) {
        // Take x piles: get suffix[i] - dp[i+x][max(m,x)] of what's left
        dp[i][m] = Math.max(
          dp[i][m],
          suffix[i] - dp[i + x][Math.max(m, x)]
        );
      }
    }
  }
  return dp[0][1];
}
// Time: O(n³), Space: O(n²)

// Stone Game IV (LC 1510) — Remove any perfect square; player who can't move loses
function winnerSquareGame(n: number): boolean {
  // dp[i] = true if current player WINS with i stones remaining
  const dp = new Array(n + 1).fill(false);
  const squares: number[] = [];
  for (let i = 1; i * i <= n; i++) squares.push(i * i);

  for (let stones = 1; stones <= n; stones++) {
    for (const sq of squares) {
      if (sq > stones) break;
      if (!dp[stones - sq]) { // if opponent LOSES after we take sq
        dp[stones] = true;
        break;
      }
    }
  }
  return dp[n];
}
// Time: O(n√n), Space: O(n)

10.1 TSP-Style — Shortest Path Visiting All Nodes (LC 847)

// dp[mask][node] = min steps to reach 'node' having visited nodes in 'mask'
// LC 847

function shortestPathLength(graph: number[][]): number {
  const n = graph.length;
  const FULL = (1 << n) - 1; // all nodes visited bitmask

  if (n === 1) return 0;

  // BFS for shortest path (not DFS — we want minimum steps)
  // State: [mask, node]
  const dist: number[][] = Array.from({ length: 1 << n }, () =>
    new Array(n).fill(Infinity),
  );
  const queue: [number, number][] = []; // [mask, node]

  // Start from every node simultaneously (multi-source)
  for (let i = 0; i < n; i++) {
    dist[1 << i][i] = 0;
    queue.push([1 << i, i]);
  }

  let head = 0;
  while (head < queue.length) {
    const [mask, node] = queue[head++];
    const d = dist[mask][node];

    if (mask === FULL) return d; // ✅ Found shortest path visiting all nodes

    for (const neighbor of graph[node]) {
      const newMask = mask | (1 << neighbor);
      if (d + 1 < dist[newMask][neighbor]) {
        dist[newMask][neighbor] = d + 1;
        queue.push([newMask, neighbor]);
      }
    }
  }

  return -1;
}
// Time: O(2^n * n²), Space: O(2^n * n)

10.2 Bitmask DP — Minimum Cost to Connect All (TSP bottom-up)

// dp[mask][i] = min cost to visit all nodes in mask, ending at node i
// Classic TSP formulation

function tsp(cost: number[][]): number {
  const n = cost.length;
  const FULL = (1 << n) - 1;
  const INF = Infinity;

  // dp[mask][i] = min cost to visit nodes in mask, last visited = i
  const dp: number[][] = Array.from({ length: 1 << n }, () =>
    new Array(n).fill(INF),
  );
  dp[1][0] = 0; // start at node 0, visited = {0}

  for (let mask = 1; mask < 1 << n; mask++) {
    for (let last = 0; last < n; last++) {
      if (dp[mask][last] === INF) continue;
      if (!(mask & (1 << last))) continue; // last must be in mask

      for (let next = 0; next < n; next++) {
        if (mask & (1 << next)) continue; // next must NOT be in mask
        const newMask = mask | (1 << next);
        dp[newMask][next] = Math.min(
          dp[newMask][next],
          dp[mask][last] + cost[last][next],
        );
      }
    }
  }

  // Return to start (if needed): min over all last nodes of dp[FULL][last] + cost[last][0]
  let ans = INF;
  for (let last = 1; last < n; last++) {
    ans = Math.min(ans, dp[FULL][last] + cost[last][0]);
  }
  return ans;
}
// Time: O(2^n * n²), Space: O(2^n * n)

10.3 Bitmask DP — Optimal Assignment (LC 1125)

// Assign skills to people to cover all skills with min people
// dp[mask] = min people to cover skill subset represented by mask
// LC 1125

function smallestSufficientTeam(
  req_skills: string[],
  people: number[][],
): number[] {
  const skillIndex = new Map(req_skills.map((s, i) => [s, i]));
  const m = req_skills.length;
  const n = people.length;
  const FULL = (1 << m) - 1;

  // Precompute bitmask for each person's skills
  const personMask = people.map((skills) =>
    skills.reduce((mask, s) => mask | (1 << skillIndex.get(s)!), 0),
  );

  // dp[mask] = min team indices to cover 'mask' skills
  const dp: number[][] = new Array(1 << m).fill(null).map(() => []);
  dp[0] = []; // empty team covers no skills

  for (let mask = 0; mask <= FULL; mask++) {
    if (dp[mask] === null) continue;

    for (let p = 0; p < n; p++) {
      const newMask = mask | personMask[p];
      if (
        dp[newMask].length === 0 ||
        dp[mask].length + 1 < dp[newMask].length
      ) {
        dp[newMask] = [...dp[mask], p];
      }
    }
  }

  return dp[FULL];
}
// Time: O(2^m * n), Space: O(2^m)

10.4 Bitmask DP — Partition to K Equal Subsets (LC 698 / 1723)

TRAP: "partition into k equal-sum subsets" is NOT plain subset-sum knapsack when
k > 2. You must track WHICH elements are used across ALL k buckets at once.
State = bitmask of used elements. dp[mask] = remainder of the CURRENT bucket
being filled (sum so far mod target). One pass fills bucket after bucket.
// LC 698 — Partition to K Equal Sum Subsets (n ≤ 16 → bitmask)
function canPartitionKSubsets(nums: number[], k: number): boolean {
  const total = nums.reduce((a, b) => a + b, 0);
  if (total % k !== 0) return false;
  const target = total / k;
  if (Math.max(...nums) > target) return false;

  const n = nums.length;
  const FULL = (1 << n) - 1;

  // dp[mask] = remaining capacity of the bucket currently being filled,
  //            given that 'mask' elements are already placed.
  // -1 = state unreachable. When mask=FULL, all k buckets filled exactly.
  const dp = new Array(1 << n).fill(-1);
  dp[0] = 0; // no elements used, current bucket empty (used 0 of target)

  for (let mask = 0; mask <= FULL; mask++) {
    if (dp[mask] === -1) continue; // unreachable
    for (let i = 0; i < n; i++) {
      if (mask & (1 << i)) continue;            // element i already used
      if (dp[mask] + nums[i] > target) continue; // overflows current bucket
      const next = mask | (1 << i);
      // (dp[mask] + nums[i]) % target: when a bucket hits target it wraps to 0,
      // automatically starting the next bucket.
      dp[next] = (dp[mask] + nums[i]) % target;
    }
  }
  return dp[FULL] === 0;
}
// Time: O(2^n · n), Space: O(2^n)
// ⭐ KEY INSIGHT: dp[mask] = fill level of the CURRENT bucket (mod target).
//   Wrapping mod target seamlessly rolls into the next bucket — no need to
//   track bucket index separately.
// SDE3 SIGNAL: "k>2 equal partition isn't subset-sum; I track a used-bitmask
//   and the running fill of one bucket at a time, sorting desc to prune faster."
// PRUNE: sort nums descending first → fails fast, large constant-factor speedup.

11.1 Tree DP — Max Path Sum (LC 124)

// ⭐ Two different DPs in one problem:
// 1. maxGain(node) = max contribution from this node going UP (used internally)
// 2. global maxPath updated at each node (the actual answer)

function maxPathSum(root: TreeNode | null): number {
  let globalMax = -Infinity;

  function maxGain(node: TreeNode | null): number {
    if (!node) return 0;

    // Only extend if positive (don't take negative branches)
    const leftGain = Math.max(0, maxGain(node.left));
    const rightGain = Math.max(0, maxGain(node.right));

    // ⭐ Update global max: path that TURNS at this node (can't extend further up)
    globalMax = Math.max(globalMax, node.val + leftGain + rightGain);

    // Return: max linear extension going UP (can only use ONE branch)
    return node.val + Math.max(leftGain, rightGain);
  }

  maxGain(root);
  return globalMax;
}
// Time: O(n), Space: O(h) call stack
// KEY: Return value ≠ answer. Return value = contribution to parent. Answer = globalMax.

11.2 Tree DP — House Robber III (LC 337)

// dp[node] = [max if not robbed, max if robbed]

function rob_tree(root: TreeNode | null): number {
  function dp(node: TreeNode | null): [number, number] {
    // [not robbed, robbed]
    if (!node) return [0, 0];

    const [leftNotRobbed, leftRobbed] = dp(node.left);
    const [rightNotRobbed, rightRobbed] = dp(node.right);

    // If we DON'T rob this node, children can be robbed or not
    const notRobbed =
      Math.max(leftNotRobbed, leftRobbed) +
      Math.max(rightNotRobbed, rightRobbed);

    // If we DO rob this node, children CANNOT be robbed
    const robbed = node.val + leftNotRobbed + rightNotRobbed;

    return [notRobbed, robbed];
  }

  const [notRobbed, robbed] = dp(root);
  return Math.max(notRobbed, robbed);
}
// Time: O(n), Space: O(h)

11.3 Tree DP — Diameter of Binary Tree (LC 543)

function diameterOfBinaryTree(root: TreeNode | null): number {
  let maxDiameter = 0;

  function height(node: TreeNode | null): number {
    if (!node) return 0;
    const left = height(node.left);
    const right = height(node.right);
    maxDiameter = Math.max(maxDiameter, left + right); // diameter through this node
    return 1 + Math.max(left, right); // height returned to parent
  }

  height(root);
  return maxDiameter;
}

11.4 Tree Rerooting DP (Sum of Distances) — LC 834

PATTERN: compute an answer for EVERY node as root, in O(n) total (not O(n²)).
TWO PASSES on a general tree (adjacency list, n nodes):
  Pass 1 (post-order, root at 0): for each node compute
     count[v] = size of its subtree,  res[0] = sum of distances from node 0.
  Pass 2 (pre-order, push down): derive res[child] from res[parent] in O(1):
     res[child] = res[parent] - count[child] + (n - count[child])
     (moving the root across edge parent→child: count[child] nodes get 1 closer,
      the other n - count[child] nodes get 1 farther.)
// LC 834 — Sum of Distances in Tree. Answer[i] = sum of dist from i to all nodes.
function sumOfDistancesInTree(n: number, edges: number[][]): number[] {
  const g: number[][] = Array.from({ length: n }, () => []);
  for (const [a, b] of edges) { g[a].push(b); g[b].push(a); }

  const count = new Array(n).fill(1); // subtree sizes (rooted at 0)
  const res = new Array(n).fill(0);   // answer per node

  // Pass 1: post-order from root 0. Accumulate res[0] and subtree counts.
  function post(node: number, parent: number): void {
    for (const child of g[node]) {
      if (child === parent) continue;
      post(child, node);
      count[node] += count[child];
      // distances from node to its subtree = child's contribution + one edge each
      res[node] += res[child] + count[child];
    }
  }

  // Pass 2: pre-order. Reroot from parent to child in O(1).
  function pre(node: number, parent: number): void {
    for (const child of g[node]) {
      if (child === parent) continue;
      res[child] = res[node] - count[child] + (n - count[child]);
      pre(child, node);
    }
  }

  post(0, -1);
  pre(0, -1);
  return res;
}
// Time: O(n), Space: O(n)
// ⭐ KEY INSIGHT: Don't recompute each root from scratch (O(n²)). Compute ONE root
//   fully, then slide the root along each edge with an O(1) update formula.
// SDE3 SIGNAL: "This is a rerooting problem — I compute the answer at one root in a
//   post-order pass, then propagate to all other roots in a pre-order pass, O(n)."
// USE WHEN: "answer for every node treated as root", "for each starting node ...".

12.1 DP on DAG — Longest Path (LC 329)

// dp[i] = length of longest increasing path starting at cell i
// LC 329 — Memoized DFS on implicit DAG

function longestIncreasingPath(matrix: number[][]): number {
  const m = matrix.length,
    n = matrix[0].length;
  const memo: number[][] = Array.from({ length: m }, () =>
    new Array(n).fill(0),
  );
  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];

  function dfs(r: number, c: number): number {
    if (memo[r][c] !== 0) return memo[r][c]; // cache hit

    let best = 1; // min path length is 1 (just this cell)
    for (const [dr, dc] of dirs) {
      const nr = r + dr,
        nc = c + dc;
      if (
        nr >= 0 &&
        nr < m &&
        nc >= 0 &&
        nc < n &&
        matrix[nr][nc] > matrix[r][c]
      ) {
        best = Math.max(best, 1 + dfs(nr, nc));
      }
    }

    memo[r][c] = best;
    return best;
  }

  let ans = 0;
  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      ans = Math.max(ans, dfs(r, c));
    }
  }

  return ans;
}
// Time: O(m*n) — each cell computed once. Space: O(m*n)
// KEY: No visited set needed because we only move to STRICTLY LARGER values (DAG).

// Count numbers in [1, n] satisfying digit constraints
// Template: dp(pos, tight, sum, started)

function countNumbersWithUniqueDigits(n: number): number {

  // Use combinatorics instead of full digit DP for this specific problem
  // But the TEMPLATE below handles general digit DP

  if (n === 0) return 1;
  let result = 10; // 0-9
  let uniqueDigits = 9; // first position: 9 choices (1-9)
  let availableChoices = 9; // remaining positions: decreasing

  for (let i = 2; i <= n; i++) {
    uniqueDigits *= availableChoices;
    result += uniqueDigits;
    availableChoices--;
  }

  return result;
}

// General Digit DP Template (memoized top-down):
function digitDP_template(n: number): number {
  const digits = String(n).split("").map(Number);
  const len = digits.length;
  // memo[pos][tight][...other state]
  const memo = new Map<string, number>();

  function dp(pos: number, tight: boolean, sum: number): number {
    if (pos === len) return sum; // return whatever we're counting

    const key = `${pos},${tight},${sum}`;
    if (memo.has(key)) return memo.get(key)!;

    const limit = tight ? digits[pos] : 9;
    let result = 0;

    for (let d = 0; d <= limit; d++) {
      result += dp(pos + 1, tight && d === limit, sum + d);
    }

    memo.set(key, result);
    return result;
  }

  return dp(0, true, 0);
}
// Time: O(len * 2 * sum_range * 10), Space: O(len * 2 * sum_range)

12.3 Probability / Expected-Value DP (A Distinct Flavor)

RECOGNIZE IT: "probability that...", "expected number of...", outcomes have
weights/chances. dp holds a FLOAT (probability or expectation), not a count.
TWO RECURRENCE STYLES:
  Probability: dp[state] = Σ P(transition) · dp[next]      (forward chances)
  Expectation: E[state]  = Σ P(transition) · (cost + E[next])
KEY TRICKS: sliding-window sum for uniform transitions; convergence pruning when
probabilities get astronomically small.
// LC 688 — Knight Probability in Chessboard.
// dp[step][r][c] = probability knight is on (r,c) after 'step' moves.
function knightProbability(n: number, k: number, row: number, col: number): number {
  const moves = [[1,2],[2,1],[-1,2],[-2,1],[1,-2],[2,-1],[-1,-2],[-2,-1]];
  let dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));
  dp[row][col] = 1;

  for (let step = 0; step < k; step++) {
    const next: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));
    for (let r = 0; r < n; r++)
      for (let c = 0; c < n; c++) {
        if (dp[r][c] === 0) continue;
        for (const [dr, dc] of moves) {
          const nr = r + dr, nc = c + dc;
          if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue; // fell off → lost
          next[nr][nc] += dp[r][c] / 8; // each of 8 moves equally likely
        }
      }
    dp = next;
  }

  let total = 0;
  for (let r = 0; r < n; r++) for (let c = 0; c < n; c++) total += dp[r][c];
  return total; // prob of still being on the board after k moves
}
// Time: O(k · n² · 8), Space: O(n²)

// LC 837 — New 21 Game (sliding-window probability — the SDE3 trick)
// dp[i] = probability of reaching exactly score i.
// Naive: dp[i] = (1/maxPts) · Σ dp[i-maxPts .. i-1]  → O(n · maxPts)
// Optimize: maintain a rolling window sum → O(n).
function new21Game(n: number, k: number, maxPts: number): number {
  if (k === 0 || n >= k + maxPts) return 1; // can't bust → certainty
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;
  let windowSum = 1;   // Σ of dp[i-maxPts .. i-1] for draws still allowed
  let result = 0;

  for (let i = 1; i <= n; i++) {
    dp[i] = windowSum / maxPts;            // each reachable prev draws to i
    if (i < k) windowSum += dp[i];          // still allowed to draw from i
    else result += dp[i];                   // i >= k → game stops, count it
    if (i - maxPts >= 0) windowSum -= dp[i - maxPts]; // slide window
  }
  return result;
}
// Time: O(n), Space: O(n)
// ⭐ KEY INSIGHT: uniform transitions over a fixed range → replace the inner
//   Σ with a sliding-window sum. This O(maxPts)→O(1) step is the whole problem.
// SDE3 SIGNAL: "Transitions are uniform over a contiguous range, so I keep a
//   running window sum instead of re-summing — drops it from O(n·maxPts) to O(n)."
// CONVERGENCE PRUNING (LC 808 Soup Servings): for large n, probability → 1 fast;
//   return 1.0 once n exceeds a threshold (~4800) to avoid overflow/time.

// JavaScript numbers are 64-bit floats. Safe integer range: -(2^53-1) to 2^53-1.
// For count DPs where answer can exceed 2^53, use BigInt or modular arithmetic.
// ❌ WRONG — silently wrong answer when count exceeds 2^53
const dp_count = new Array(n).fill(0);
dp_count[i] = dp_count[i-1] + dp_count[i-2]; // might overflow silently

// ✅ CORRECT option 1 — modular arithmetic (when problem says mod 10^9+7)
const MOD = 1_000_000_007;
dp_count[i] = (dp_count[i-1] + dp_count[i-2]) % MOD;

// ✅ CORRECT option 2 — BigInt (when problem needs exact large count)
const dpBig: bigint[] = new Array(n).fill(0n);
dpBig[i] = dpBig[i-1] + dpBig[i-2]; // exact, no overflow
// Return as Number at the end: Number(dpBig[n])

// GOTCHA 10: Use Int32Array / Float64Array for large DP tables (performance)
// Regular Array of numbers uses object heap. Typed arrays use contiguous memory.
// For large dp tables (n > 10^4), typed arrays are 3-5x faster in practice.
// ❌ SLOWER for large n
const dp_slow = new Array(n).fill(0);         // object array
const dp2D_slow = Array.from({length: n}, () => new Array(m).fill(0));

// ✅ FASTER for large n (contiguous memory, cache-friendly)
const dp_fast = new Int32Array(n);            // for integer DP
const dp_float = new Float64Array(n);         // for float DP (probability DP)
//NOTE: Typed arrays initialize to 0 by default — no .fill(0) needed.
//NOTE: Cannot store Infinity in Int32Array — use regular Array for distance DP.

// GOTCHA 11: For-of on string iterates Unicode code points (usually fine)
// But be careful with emoji / surrogate pairs in string DP problems
for (const ch of s) {
  /* ch is a full Unicode character */
}
// vs
for (let i = 0; i < s.length; i++) {
  const ch = s[i]; /* s[i] is a UTF-16 code unit */
}

D&C DP Optimization — When opt[i][j] is Monotone

// Applies when dp[i][j] = min over k of (dp[i-1][k] + cost(k+1, j))
// AND opt[i][j] (the optimal k) is non-decreasing in j.
// Reduces O(n²) inner loop to O(n log n) via divide and conquer on j.

// TEMPLATE (do NOT memorize for interviews — just know the NAME and CONDITION):
function dcDP(n: number, cost: (l: number, r: number) => number): number[] {
  let dp = new Array(n + 1).fill(Infinity);
  dp[0] = 0;

  function solve(lo: number, hi: number, optLo: number, optHi: number, prev: number[]): void {
    if (lo > hi) return;
    const mid = (lo + hi) >> 1;
    let best = Infinity, opt = optLo;

    for (let k = optLo; k <= Math.min(mid - 1, optHi); k++) {
      const val = prev[k] + cost(k + 1, mid);
      if (val < best) { best = val; opt = k; }
    }
    dp[mid] = best;
    solve(lo, mid - 1, optLo, opt, prev);
    solve(mid + 1, hi, opt, optHi, prev);
  }

  const prev = [...dp];
  solve(1, n, 0, n - 1, prev);
  return dp;
}
// SDE3 SIGNAL: "This is an O(n²) DP, but if the cost function satisfies
// the quadrangle inequality (w(a,c) + w(b,d) ≤ w(a,d) + w(b,c) for a≤b≤c≤d),
// I can apply Knuth's optimization for O(n²) interval DP or the D&C trick
// for O(n log n) on row-by-row DP."
