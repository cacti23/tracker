Q1 — Leaf (or leaves) with the maximum root-to-leaf value
The post says: “return all the leaf node of the binary tree with the maximum value from root to leaf node in the path”. The wording is unclear. Most likely meaning: return every leaf whose root-to-leaf sum is the maximum, ties included. If only the best sum is wanted, drop the list and keep best.
Closest matches

⏱️ TC: O(n), every node is visited once
📦 SC: O(h) for the recursion, plus the list of tied leaves
maxPathLeaves.ts
function maxPathLeaves(root: TreeNode | null): TreeNode[] {
    let best = -Infinity;
    let leaves: TreeNode[] = [];

    function dfs(node: TreeNode | null, sum: number): void {
        if (!node) return;
        sum += node.val;

        if (!node.left && !node.right) {
            if (sum > best) { best = sum; leaves = [node]; }   // new best, start a fresh list
            else if (sum === best) leaves.push(node);          // tie, keep it too
            return;
        }

        dfs(node.left, sum);
        dfs(node.right, sum);
    }

    dfs(root, 0);
    return leaves;
}
Q2 — Longest word reducible to length 1
Delete one character at a time. Every shorter word must stay in the dictionary. Find the longest word that can reach length 1 this way. Example: string → sring → sing → ing → ng → g gives length 6.
Closest matches
LC 1048 — Longest String Chain LC 720 — Longest Word in Dictionary
🪜 canReduce(word) answers one yes/no question: can this word shrink to a single letter, with every step landing on a dictionary word? One working path is enough, so return true the moment you find it. A reducible word's chain is exactly as long as the word, so there is nothing to count.
⏱️ TC: exponential in the worst case, because the same shorter word is re-tried through different delete orders
📦 SC: O(L), the recursion depth (L = word length)
longestValidWord.ts — base (no memo)
function longestValidWord(words: string[]): number {
    const wordSet = new Set(words);

    // can `word` be reduced to a single character, with every step in the dictionary?
    function canReduce(word: string): boolean {
        if (word.length === 1) return wordSet.has(word);   // 🛑 base case

        for (let i = 0; i < word.length; i++) {
            const next = word.slice(0, i) + word.slice(i + 1);

            if (wordSet.has(next) && canReduce(next)) return true;  // 🏆 one path is enough
        }

        return false;                                       // ❌ dead end
    }

    let maxLen = 0;

    for (const word of words) {
        if (canReduce(word)) maxLen = Math.max(maxLen, word.length);  // 📏 the chain length is the word's length
    }

    return maxLen;
}
⏱️ TC (follow-up): O(D · L²), each distinct word fails at most once, and each try costs an O(L) slice
📦 SC: O(D · L) for the dead set
🔁 The follow-up is a 3-line change to the code above: remember the words that already failed.
longestValidWord.ts — follow-up: skip known dead ends
    const dead = new Set<string>(); // ➕ words already proven NOT reducible

    function canReduce(word: string): boolean {
        if (word.length === 1) return wordSet.has(word);
        if (dead.has(word)) return false;           // ➕ seen this dead end before

        for (let i = 0; i < word.length; i++) {
            const next = word.slice(0, i) + word.slice(i + 1);
            if (wordSet.has(next) && canReduce(next)) return true;
        }

        dead.add(word);                                // ➕ remember it
        return false;
    }

function parseTimeToMinutes(time: string): number {
    const match = time.match(/(\d{1,2}):(\d{2})\s*(AM|PM)/i);
    if (!match) throw new Error("Invalid time format");

    const [, hourStr, minuteStr, meridiem] = match;
    let hour = parseInt(hourStr, 10) % 12;
    const minute = parseInt(minuteStr, 10);

    if (meridiem.toUpperCase() === "PM") hour += 12;

    return hour * 60 + minute;
}
minBlocksGreedy.ts — the attempt that breaks
function minBlocksGreedy(target: number, blocks: number[]): number {
    const sorted = [...blocks].sort((a, b) => b - a);
    let remaining = target;
    let count = 0;

    // ⚠️ Only correct when the block sizes are "canonical" (like normal coins) —
    // this is the assumption new constraints break
    for (const block of sorted) {
        while (remaining >= block) {
            remaining -= block;
            count++;
        }
    }

    return remaining === 0 ? count : -1;
}
minBlocksDP.ts — the fix, once greedy breaks
function minBlocksDP(target: number, blocks: number[]): number {
    const dp = new Array(target + 1).fill(Infinity);
    dp[0] = 0;

    for (let t = 1; t <= target; t++) {
        for (const block of blocks) {
            if (block <= t) dp[t] = Math.min(dp[t], dp[t - block] + 1);
        }
    }

    return dp[target] === Infinity ? -1 : dp[target];
}

Design a user model, then a friend-recommendation system
Standard graphs store one flat neighbour list per node. Here: design a data model for a user on a social platform, then build friend recommendations on top of it — typically ranking friends-of-friends by mutual-connection count.

AlgoMaster — Design a Social Network (LLD) Prepfully — Design a social network's friend recommendation system
⏱️ TC: O(F · F₂) for a recommendation call, F = direct friends, F₂ = average friends-of-friends per friend. 📦 SC: O(U + E) overall — U users, E friendships stored.
SocialGraph.ts
class SocialGraph {
    private friends = new Map<string, Set<string>>();

    addFriendship(userA: string, userB: string): void {
        if (!this.friends.has(userA)) this.friends.set(userA, new Set());
        if (!this.friends.has(userB)) this.friends.set(userB, new Set());

        this.friends.get(userA)!.add(userB);
        this.friends.get(userB)!.add(userA);
    }

    recommendFriends(user: string): string[] {
        const direct = this.friends.get(user) ?? new Set();
        const mutualCount = new Map<string, number>();

        // Look at friends-of-friends
        for (const friend of direct) {
            for (const candidate of this.friends.get(friend) ?? []) {
                // Skip self and existing friends
                if (candidate === user || direct.has(candidate)) continue;

                mutualCount.set(candidate, (mutualCount.get(candidate) ?? 0) + 1);
            }
        }

        // Rank by mutual-friend count, highest first
        return [...mutualCount.entries()]
            .sort((a, b) => b[1] - a[1])
            .map(([id]) => id);
    }
}

A plain object turns every key into a string (adj[1] and adj["1"] are the same key) and can clash with built-in names like "constructor". A Map takes any key type, has .size, and keeps insertion order. Pick array for dense numeric ids, Map otherwise.
  2. Inner container (type → neighbours): object, Map or a fixed type list? If the relationship types are a small fixed set, write them as a TypeScript type, type Rel = "friend" | "colleague" | "family", and use Record<Rel, number[]>. The compiler then catches a misspelled type. If new types can appear at runtime, use Map<string, number[]>.
  3. Neighbour list: array or Set? An array is cheapest to build and loop over, but allows duplicate edges and makes “is X a neighbour?” or “remove this edge” O(degree). A Set removes duplicates and makes those O(1), at more memory.
  4. Grouped by type vs one list of edge objects. Grouping (adj[1].friend) makes “walk only friend edges” touch only those edges. A flat list adj[1] = [{ to: 2, type: "friend" }] must filter every time, but is easier when edges gain more fields (weight, date). Say which queries matter most, then pick.
  5. Empty types: store type3: [] for every node, or leave it out and read ?? []? Leaving it out saves memory; the traversal below reads ?? [] so both work.
  6. Likely follow-ups: walk edges of a set of types (check allowed.has(type) in the loop); directed vs two-way edges (add the reverse edge, maybe with its own type, like parent/child); a path whose types must follow a pattern (BFS over (node, step in the pattern) pairs instead of nodes).
No LeetCode equivalent
⏱️ TC: O(V + E) — standard BFS/DFS bound, still holds since every edge is visited once regardless of its type. 📦 SC: O(V) — visited set + queue.
traverseByType.ts
type EdgeType = string;
type TypedGraph = Map<number, Map<EdgeType, number[]>>;

function traverseByType(graph: TypedGraph, start: number, type: EdgeType): number[] {
    const visited = new Set<number>([start]);
    const queue: number[] = [start];
    const order: number[] = [];
    let head = 0;

    while (head < queue.length) {
        const node = queue[head++];
        order.push(node);

        const neighbours = graph.get(node)?.get(type) ?? [];

        for (const next of neighbours) {
            if (visited.has(next)) continue;
            visited.add(next);
            queue.push(next);
        }
    }

    return order;
}

In plain words: cut the string in at most 2 places, so you get at most 3 pieces. Hand every piece to Alice or Bob. When you’re done, both must hold the same number of a’s and the same number of b’s. Return where you cut.

Example: s = "aabb" (2 a’s, 2 b’s). Cut at 1 and 3 → pieces "a" | "ab" | "b". Alice gets the middle "ab", Bob gets "a" + "b". Each has 1 a and 1 b, so return [1, 3]. For "abba" one cut is enough: "ab" | "ba" → [2].
No LeetCode match
LC 1013 — Partition Array Into Three Parts With Equal Sum (loosely related concept only)
🪟 The key idea: 2 cuts → 3 pieces L | M | R. However you hand them out, one person always holds one unbroken window (M, L+M or M+R).
🎯 So just find one window with half the a’s + half the b’s. It doesn’t matter if it’s Alice’s or Bob’s.
⚖️ The rest is then automatically half + half too (total − half = half) ✅
🔎 How to find it: window = prefix(end) − prefix(start), so at each end look up prefix(end) − half in the Map.
🔪 The window’s start and end are the cuts (0 or n = no cut there).
🧪 Checked against brute force on 20,000 random strings (every way to hand out the pieces): 0 mismatches.
splitAliceBob.ts
// TC: O(n), one count pass + one prefix pass
// SC: O(n), the Map holds at most n + 1 prefix pairs
function splitAliceBob(s: string): [number, number] | null {
    let totalA = 0;
    let totalB = 0;
    for (const ch of s) {
        if (ch === 'a') totalA++;
        else totalB++;
    }

    // 1. odd count of a or b → can't split equally
    if (totalA % 2 !== 0 || totalB % 2 !== 0) return null;

    const halfA = totalA / 2;
    const halfB = totalB / 2;
    if (s.length === 0) return [0, 0];

    // 2. find a middle piece s[start..end) that holds exactly (halfA, halfB)
    const firstSeen = new Map<string, number>(); // "a,b" prefix counts → earliest index
    firstSeen.set('0,0', 0);

    let prefixA = 0;
    let prefixB = 0;
    for (let end = 1; end <= s.length; end++) {
        if (s[end - 1] === 'a') prefixA++;
        else prefixB++;

        // piece = prefix(end) − prefix(start) must equal (halfA, halfB)
        const start = firstSeen.get(`${prefixA - halfA},${prefixB - halfB}`);
        if (start !== undefined) return [start, end]; // cuts at start and end (0 or n = no cut there)

        const key = `${prefixA},${prefixB}`;
        if (!firstSeen.has(key)) firstSeen.set(key, end);
    }

    return null;
}

canSplitAfterRemoval.ts
function canSplitAfterRemoval(nums: number[]): boolean {
    const n = nums.length;
    let total = 0;
    const first = new Map<number, number>(); // value → first index
    const last = new Map<number, number>();  // value → last index
    for (let i = 0; i < n; i++) {
        total += nums[i];
        if (!first.has(nums[i])) first.set(nums[i], i);
        last.set(nums[i], i);
    }

    let left = 0;
    for (let cut = 1; cut < n; cut++) {      // left = nums[0..cut-1], right = nums[cut..]
        left += nums[cut - 1];
        const diff = left - (total - left);  // how much heavier the left is

        // remove diff from the left: needs one other element left behind
        const li = first.get(diff);
        if (li !== undefined && li < cut && cut >= 2) return true;

        // remove -diff from the right: needs one other element left behind
        const ri = last.get(-diff);
        if (ri !== undefined && ri >= cut && n - cut >= 2) return true;
    }
    return false;
}

function luckyNumbers() {
  const isLucky = (n: number): boolean => /^[47]+$/.test(String(n));

  // BFS from 4, 7 yields lucky numbers in increasing order
  const luckyUpTo = (limit: number): number[] => {
    const out: number[] = [];
    const queue = [4, 7];
    for (let i = 0; i < queue.length; i++) {
      const cur = queue[i];
      if (cur > limit) break; // everything after is bigger
      out.push(cur);
      queue.push(cur * 10 + 4, cur * 10 + 7);
    }
    return out;
  };

  // next lucky has at most one more digit than n
  const nextLucky = (n: number): number =>
    luckyUpTo(10 ** (String(n).length + 1)).find((x) => x > n)!;

  const luckyBetween = (a: number, b: number): number[] =>
    luckyUpTo(b).filter((x) => x >= a);

  return { isLucky, nextLucky, luckyBetween };
}

function validDirections(rules: string[]): boolean {
  // edge a -> b: a is strictly north of b (ns), or strictly east of b (ew)
  const ns = new Map<string, string[]>();
  const ew = new Map<string, string[]>();

  const addEdge = (g: Map<string, string[]>, from: string, to: string) => {
    if (!g.has(from)) g.set(from, []);
    g.get(from)!.push(to);
  };

  for (const rule of rules) {
    const [a, dir, b] = rule.split(' '); // e.g. "P1 NE P2"
    if (dir.includes('N')) addEdge(ns, a, b);
    if (dir.includes('S')) addEdge(ns, b, a);
    if (dir.includes('E')) addEdge(ew, a, b);
    if (dir.includes('W')) addEdge(ew, b, a);
  }

  // a cycle means "A north of B ... north of A": impossible
  const hasCycle = (g: Map<string, string[]>): boolean => {
    const state = new Map<string, number>(); // 1 = on current path, 2 = done
    const dfs = (u: string): boolean => {
      if (state.get(u) === 1) return true;
      if (state.get(u) === 2) return false;
      state.set(u, 1);
      for (const v of g.get(u) ?? []) if (dfs(v)) return true;
      state.set(u, 2);
      return false;
    };
    return [...g.keys()].some(dfs);
  };

  return !hasCycle(ns) && !hasCycle(ew);
}

function sumOfApSubarrays(nums: number[]): number {
  let total = 0;
  let len = 0; // length of the longest AP subarray ending at i
  let sum = 0; // sum of all AP subarrays ending at i

  for (let i = 0; i < nums.length; i++) {
    const continues = i >= 2 && nums[i] - nums[i - 1] === nums[i - 1] - nums[i - 2];
    if (i < 2 || continues) {
      len += 1;
      sum += nums[i] * len; // every AP ending at i-1 grows by nums[i], plus [nums[i]] alone
    } else {
      len = 2; // any pair is an AP
      sum = nums[i - 1] + 2 * nums[i]; // [prev, cur] and [cur]
    }
    total += sum;
  }
  return total;
}

// parent[i] = index of node i's parent, -1 for the root
function removeSubtree(parent: number[], target: number): number[] {
  const n = parent.length;
  const children: number[][] = Array.from({ length: n }, () => []);
  parent.forEach((p, i) => { if (p >= 0) children[p].push(i); });

  // mark target and everything below it
  const removed = new Array<boolean>(n).fill(false);
  const dfs = (u: number) => {
    removed[u] = true;
    for (const c of children[u]) dfs(c);
  };
  dfs(target);

  // a kept node's new index = how many kept nodes come before it
  const newIndex = new Array<number>(n).fill(-1);
  let next = 0;
  for (let i = 0; i < n; i++) if (!removed[i]) newIndex[i] = next++;

  const out: number[] = [];
  for (let i = 0; i < n; i++)
    if (!removed[i]) out.push(parent[i] === -1 ? -1 : newIndex[parent[i]]);
  return out;
}

// Round 2: merge two iterators, each value returned once
function mergeDedupingIterator<T>(a: Iter<T>, b: Iter<T>): Iter<T> {
  const seen = new Set<T>();
  let buffered: T | undefined;
  let hasBuffered = false;

  // move to the next value not seen yet: drain a first, then b
  const advance = () => {
    for (const it of [a, b]) {
      while (it.hasNext()) {
        const v = it.next();
        if (!seen.has(v)) { seen.add(v); buffered = v; hasBuffered = true; return; }
      }
    }
  };

  return {
    hasNext() { if (!hasBuffered) advance(); return hasBuffered; },
    next() {
      if (!this.hasNext()) throw new Error('no more elements');
      hasBuffered = false;
      return buffered as T;
    },
  };
}

function removeFirstMatchingNode(root: XmlNode | null, tagname: string): XmlNode | null {
  if (!root) return null;
  if (root.tag === tagname) return null; // the root itself matches

  // true once a match is removed, so we stop searching
  const dfs = (node: XmlNode): boolean => {
    for (let i = 0; i < node.children.length; i++) {
      if (node.children[i].tag === tagname) { node.children.splice(i, 1); return true; }
      if (dfs(node.children[i])) return true;
    }
    return false;
  };
  dfs(root);
  return root;
}

type Card = { suit: number; rank: number };

// Round 1: highest straight flush (5 same-suit cards with consecutive ranks)
function findHighestStraightFlush(cards: Card[], suits = 4, ranks = 13): Card[] {
  // has[s][r] = true if we hold that card
  const has = Array.from({ length: suits }, () => new Array<boolean>(ranks).fill(false));
  for (const c of cards) has[c.suit][c.rank] = true;

  let bestSuit = -1;
  let bestTop = -1; // highest rank that ends a run of 5
  for (let s = 0; s < suits; s++) {
    let run = 0;
    for (let r = 0; r < ranks; r++) {
      run = has[s][r] ? run + 1 : 0;
      if (run >= 5 && r > bestTop) { bestTop = r; bestSuit = s; }
    }
  }
  if (bestTop === -1) return []; // no straight flush

  const out: Card[] = [];
  for (let r = bestTop - 4; r <= bestTop; r++) out.push({ suit: bestSuit, rank: r });
  return out;
}

// Round 4: parking strip from 0 to size; a car at x takes (x - 0.5, x + 0.5)
function createParkingLot(size = 10000) {
  const cars: number[] = []; // parked centres, kept sorted
  const EPS = 1e-9; // doubles like 12.4 aren't exact, so allow a tiny slack

  const canPark = (x: number): boolean => {
    if (x - 0.5 < -EPS || x + 0.5 > size + EPS) return false; // off the strip
    return cars.every(c => Math.abs(c - x) >= 1 - EPS); // touching is fine, overlap is not
  };

  const park = (x: number): void => {
    let i = 0;
    while (i < cars.length && cars[i] < x) i++;
    cars.splice(i, 0, x); // insert in order, like Insert Interval
  };

  // follow-up: is there a gap of length >= 1 anywhere?
  const isSpaceAvailable = (): boolean => {
    let freeFrom = 0; // end of the previous car (or the strip start)
    for (const c of cars) {
      if (c - 0.5 - freeFrom >= 1 - EPS) return true;
      freeFrom = c + 0.5;
    }
    return size - freeFrom >= 1 - EPS;
  };

  return { canPark, park, isSpaceAvailable };
}

// buf has spare cells at the end; only the first `size` cells are filled
function removeAsDoubleBs(buf: string[], size: number): number {
  // pass 1 (left to right): drop the As, count the Bs
  let kept = 0, bs = 0;
  for (let i = 0; i < size; i++) {
    if (buf[i] === 'A') continue;
    if (buf[i] === 'B') bs++;
    buf[kept++] = buf[i];
  }

  // pass 2 (right to left): write from the end so we never overwrite an unread cell
  const len = kept + bs;
  let w = len - 1;
  for (let r = kept - 1; r >= 0; r--) {
    if (buf[r] === 'B') buf[w--] = 'B'; // the extra copy
    buf[w--] = buf[r];
  }
  return len; // new filled length
}

type Cell = [number, number];

// No walls: walk columns first, then rows (matches the post's example). Length = Manhattan distance.
function shortestPath(from: Cell, to: Cell): Cell[] {
  let [r, c] = from;
  const path: Cell[] = [[r, c]];
  while (c !== to[1]) { c += c < to[1] ? 1 : -1; path.push([r, c]); }
  while (r !== to[0]) { r += r < to[0] ? 1 : -1; path.push([r, c]); }
  return path;
}

// Follow-up, if some cells are blocked (grid[r][c] === 1): BFS, remember each cell's parent.
function shortestPathWithWalls(grid: number[][], from: Cell, to: Cell): Cell[] {
  const m = grid.length, n = grid[0].length;
  const parent = new Map<number, number>(); // cell id -> previous cell id
  const id = (r: number, c: number) => r * n + c;
  const start = id(from[0], from[1]), end = id(to[0], to[1]);
  if (grid[from[0]][from[1]] === 1 || grid[to[0]][to[1]] === 1) return [];
  parent.set(start, -1);
  const queue = [start];
  for (let i = 0; i < queue.length && !parent.has(end); i++) {
    const r = Math.floor(queue[i] / n), c = queue[i] % n;
    for (const [dr, dc] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
      const nr = r + dr, nc = c + dc;
      if (nr < 0 || nc < 0 || nr >= m || nc >= n) continue; // off the grid
      if (grid[nr][nc] === 1 || parent.has(id(nr, nc))) continue; // wall or seen
      parent.set(id(nr, nc), queue[i]);
      queue.push(id(nr, nc));
    }
  }
  if (!parent.has(end)) return []; // no path
  // walk back from the end to the start
  const path: Cell[] = [];
  for (let cur = end; cur !== -1; cur = parent.get(cur)!) path.push([Math.floor(cur / n), cur % n]);
  return path.reverse();
}

function leafRemovalOrder(parent: number[]): number[] {
  const n = parent.length;
  const kids = new Array<number>(n).fill(0); // children not yet removed
  parent.forEach((p) => { if (p >= 0) kids[p]++; });

  const order: number[] = [];
  const fresh: number[] = []; // leaves created by a removal, kept for later
  const remove = (u: number) => {
    order.push(u);
    const p = parent[u];
    if (p >= 0 && --kids[p] === 0) fresh.push(p); // parent just became a leaf
  };

  for (let i = 0; i < n; i++) if (kids[i] === 0) remove(i); // original leaves first
  for (let i = 0; i < fresh.length; i++) remove(fresh[i]); // then fresh leaves, oldest first
  return order;
}

function findSquareCorner(grid: number[][]): [number, number] {
  const m = grid.length, n = grid[0].length;
  const k = Math.max(1, Math.floor(Math.sqrt(n))); // assumes N = number of columns

  // any k x k block contains a cell whose row and column are both multiples of k
  for (let r = 0; r < m; r += k)
    for (let c = 0; c < n; c += k)
      if (grid[r][c] === 1) {
        // walk to the top-left corner of the only square
        let i = r, j = c;
        while (i > 0 && grid[i - 1][c] === 1) i--;
        while (j > 0 && grid[r][j - 1] === 1) j--;
        return [i, j];
      }
  return [-1, -1];
}

function rangeMax(nums: number[]): (l: number, r: number) => number {
  const n = nums.length;
  // table[j][i] = max of nums[i .. i + 2^j - 1]
  const table: number[][] = [nums.slice()];
  for (let j = 1; (1 << j) <= n; j++) {
    const prev = table[j - 1];
    const row: number[] = [];
    for (let i = 0; i + (1 << j) <= n; i++) {
      row.push(Math.max(prev[i], prev[i + (1 << (j - 1))]));
    }
    table.push(row);
  }

  // answer max of nums[l..r] (inclusive) with two overlapping blocks
  const query = (l: number, r: number): number => {
    const j = 31 - Math.clz32(r - l + 1);
    return Math.max(table[j][l], table[j][r - (1 << j) + 1]);
  };
  return query;
}

function maxSumEqualEnds(nums: number[]): number {
  // best[v] = smallest prefix sum seen just before a subarray starting at value v
  const best = new Map<number, number>();
  let prefix = 0; // sum of nums[0..i-1]
  let ans = -Infinity;
  for (const x of nums) {
    // a subarray may start at this very element (single element counts)
    if (!best.has(x) || prefix < best.get(x)!) best.set(x, prefix);
    // end here: subtract the cheapest start with the same value
    ans = Math.max(ans, prefix + x - best.get(x)!);
    prefix += x;
  }
  return ans;
}

function availableByInterval(emp: number[][]): [number, number, string[]][] {
  // +1 at arrival, -1 at departure, per employee

  emp.forEach(([a, d], i) => { if (a < d) { ev.push([a, i, 1]); ev.push([d, i, -1]); } });

  const out: [number, number, string[]][] = [];
  let k = 0;
  while (k < ev.length) {
    const t = ev[k][0];
    while (k < ev.length && ev[k][0] === t) { // apply every event at time t
      if (ev[k][2] === 1) present.add(ev[k][1]); else present.delete(ev[k][1]);
      k++;
    }
    // the set now holds until the next event time
    if (k < ev.length && present.size > 0)
      out.push([t, ev[k][0], [...present].sort((a, b) => a - b).map(i => 'E' + (i + 1))]);
  }
  return out;

function fcfsSchedule(jobs: Job[]): [number, number, number][] {
  const order = [...jobs].sort((a, b) => a.start - b.start); // stable: ties keep input order
  const out: [number, number, number][] = [];

    clock += j.exec;

  return out;
}

// Q1: ways to split N identical objects into K non-empty groups (order of groups doesn't matter)
// = partitions of N into exactly K parts. Put 1 object in each group first,
// then share the other N-K objects with each group taking 0..any: coin change with coins 1..K.
function countPartitions(n: number, k: number, MOD = 1_000_000_007): number {
  if (k < 1 || k > n) return 0;
  const m = n - k;
  const dp = new Array<number>(m + 1).fill(0);
  dp[0] = 1; // one way to share nothing
  for (let part = 1; part <= k; part++)
    for (let s = part; s <= m; s++) dp[s] = (dp[s] + dp[s - part]) % MOD;
  return dp[m];
}

// Q2: shortest cycle through `src` in a directed graph; returns its nodes starting at src, [] if none
function shortestCycleFrom(n: number, edges: number[][], src: number): number[] {
  const adj: number[][] = Array.from({ length: n }, () => []);
  for (const [u, v] of edges) adj[u].push(v);

  const parent = new Array<number>(n).fill(-2); // -2 = not visited
  parent[src] = -1;
  const queue = [src];
  for (let i = 0; i < queue.length; i++) {
    const u = queue[i];
    for (const v of adj[u]) {
      if (v === src) {
        // BFS pops nodes nearest-first, so the first edge back to src closes the shortest cycle
        const path: number[] = [];
        for (let x = u; x !== -1; x = parent[x]) path.push(x);
        return path.reverse();
      }
      if (parent[v] === -2) { parent[v] = u; queue.push(v); }
    }
  }
  return [];
}

// Round 1: rows = [startIP, endIP, city]; ranges assumed not to overlap
function makeIpLookup(rows: [string, string, string][]): (ip: string) => string | null {
  // "1.0.1.9" -> one 32-bit number, so IPs compare like numbers
  const toNum = (ip: string) => ip.split('.').reduce((n, part) => n * 256 + Number(part), 0);
  const ranges = rows
    .map(([s, e, city]) => ({ start: toNum(s), end: toNum(e), city }))
    .sort((a, b) => a.start - b.start);

  return (ip: string) => {
    const x = toNum(ip);
    // binary search: last range whose start <= x
    let lo = 0, hi = ranges.length - 1, best = -1;
    while (lo <= hi) {
      const mid = (lo + hi) >> 1;
      if (ranges[mid].start <= x) { best = mid; lo = mid + 1; } else hi = mid - 1;
    }
    // x is inside only if that range has not ended yet
    return best >= 0 && x <= ranges[best].end ? ranges[best].city : null;
  };
}

// Round 2: a bond listed twice is a double bond
function isValidMolecule(atoms: Record<number, string>, bonds: number[][]): boolean {
  const need: Record<string, number> = { C: 4, O: 2, H: 1 };
  const ids = Object.keys(atoms).map(Number);
  if (ids.length === 0) return false;
  const adj = new Map<number, number[]>(ids.map(id => [id, []]));

  for (const [a, b] of bonds) {
    if (a === b || !adj.has(a) || !adj.has(b)) return false; // bad bond
    adj.get(a)!.push(b);
    adj.get(b)!.push(a);
  }
  // every atom has exactly the bonds its element needs
  for (const id of ids) if (adj.get(id)!.length !== need[atoms[id]]) return false;

  // follow-up: one molecule only, so every atom must be reachable from the first
  const seen = new Set<number>();
  const dfs = (u: number) => {
    seen.add(u);
    for (const v of adj.get(u)!) if (!seen.has(v)) dfs(v);
  };
  dfs(ids[0]);
  return seen.size === ids.length;
}

// Phone screen: start with energy k (max k). Each day: move A[i] (energy -1) or rest (energy +1, capped at k).
function maxDistance(A: number[], k: number): number {
  // best[e] = farthest distance so far, ending the day with energy e
  let best = new Array<number>(k + 1).fill(-Infinity);
  best[k] = 0;

  const step = (speed: number) => {
    const next = new Array<number>(k + 1).fill(-Infinity);
    for (let e = 0; e <= k; e++) {
      if (best[e] === -Infinity) continue;
      const r = Math.min(e + 1, k); // rest
      next[r] = Math.max(next[r], best[e]);
      if (e >= 1) next[e - 1] = Math.max(next[e - 1], best[e] + speed); // move
    }
    best = next;
  };

  for (const speed of A) step(speed);
  return Math.max(...best);
}

// Round 2: precompute the top two anagrams per hash, then answer each word in O(1).
function buildBestAnagram(dict: string[], hash: (w: string) => string) {
  const score = (w: string) => {
    let s = 0;
    for (let i = 1; i < w.length; i++) s += Math.abs(w.charCodeAt(i) - w.charCodeAt(i - 1));
    return s;
  };

  // top[h] = up to two words with this hash, highest score first
  const top = new Map<string, string[]>();
  for (const w of new Set(dict)) {
    const h = hash(w);
    const list = top.get(h) ?? [];
    list.push(w);
    list.sort((a, b) => score(b) - score(a));
    top.set(h, list.slice(0, 2));
  }

  // best anagram that is not the word itself, "" if none
  return (word: string): string => {
    for (const w of top.get(hash(word)) ?? []) if (w !== word) return w;
    return "";
  };
}

function nextWordModel(sentences: string[]) {
  const count = new Map<string, Map<string, number>>();
  const best = new Map<string, string>();

  for (const s of sentences) {
    const words = s.split(" ").filter(Boolean);
    for (let i = 0; i + 1 < words.length; i++) {
      const [w, nxt] = [words[i], words[i + 1]];
      const c = count.get(w) ?? new Map<string, number>();
      c.set(nxt, (c.get(nxt) ?? 0) + 1);
      count.set(w, c);
      // update the leader as we go, so no second pass is needed
      const lead = best.get(w);
      if (lead === undefined || c.get(nxt)! > c.get(lead)!) best.set(w, nxt);
    }
  }
  return (word: string) => best.get(word) ?? "";
}

function swipeSuggestions(path: string, dict: string[]): string[] {
  const fits = (word: string): boolean => {
    if (!word || !path) return false;
    // the swipe starts on the first letter and ends on the last one
    if (word[0] !== path[0] || word[word.length - 1] !== path[path.length - 1]) return false;
    let j = 0;
    for (let i = 0; i < word.length; i++) {
      if (i > 0 && word[i] === word[i - 1]) continue; // "ll" in hello: the finger stays on one key
      while (j < path.length && path[j] !== word[i]) j++;
      if (j === path.length) return false; // letter never passed under the finger
    }
    return true;
  };

  // longest words first: they explain more of the swipe
  return dict.filter(fits).sort((a, b) => b.length - a.length);
}

// Screen: stream of unique floats; return and remove a triplet with all gaps <= d
function makeTripletStream(d: number) {
  const sorted: number[] = []; // invariant: no valid triplet is ever left inside

  // first index with sorted[i] >= x
  const lowerBound = (x: number) => {
    let lo = 0, hi = sorted.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (sorted[mid] < x) lo = mid + 1; else hi = mid;
    }
    return lo;
  };

  return (x: number): number[] | null => {
    const i = lowerBound(x);
    sorted.splice(i, 0, x);
    // any valid triplet must use x; nearest neighbours give the tightest ones
    for (let s = Math.max(0, i - 2); s <= i && s + 2 < sorted.length; s++) {
      if (sorted[s + 2] - sorted[s] <= d) return sorted.splice(s, 3);
    }
    return null;
  };
}

// Onsite 1: ways to cut nums so every part has at least one negative
function countPartitions(nums: number[]): number {
  let ways = 0; // stays 0 if there is no negative at all
  let last = -1; // index of the previous negative
  nums.forEach((x, i) => {
    if (x >= 0) return;
    // one cut somewhere between last and i (i - last spots), or no cut
    ways = last === -1 ? 1 : ways * (i - last + 1);
    last = i;
  });
  return ways;
}

// Onsite 3: count A[i] matched to an unused B[j] with the same value and |i - j| <= d
function countValidSignals(A: number[], B: number[], d: number): number {
  const free = new Map<number, number[]>(); // value -> unused B indices, oldest first
  let added = 0, count = 0;
  for (let i = 0; i < A.length; i++) {
    // let B[0..i+d] into the window
    for (; added < B.length && added <= i + d; added++) {
      if (!free.has(B[added])) free.set(B[added], []);
      free.get(B[added])!.push(added);
    }
    const q = free.get(A[i]);
    if (!q) continue;
    while (q.length && q[0] < i - d) q.shift(); // too far left, never usable again
    // take the oldest one: it is the first to fall out of reach
    if (q.length) { q.shift(); count++; }
  }
  return count;
}

function makeUniqueLogger() {
  type Entry = { t: number; msg: string; ok: boolean };
  const pending: Entry[] = []; // in time order, not yet decided
  const lastSeen = new Map<string, Entry>();

  // entries older than t - 10 can't get a new copy within 10s: decide them
  const flushBefore = (t: number) => {
    const out: string[] = [];
    while (pending.length && pending[0].t < t - 10) {
      const e = pending.shift()!;
      if (e.ok) out.push(e.msg);
    }
    return out;
  };

  // timestamps arrive in non-decreasing order; returns messages now safe to print
  const log = (t: number, msg: string): string[] => {
    const e: Entry = { t, msg, ok: true };
    const prev = lastSeen.get(msg);
    if (prev && t - prev.t <= 10) { prev.ok = false; e.ok = false; }
    lastSeen.set(msg, e);
    pending.push(e);
    return flushBefore(t);
  };
  const end = () => flushBefore(Infinity); // stream over: decide the rest

  return { log, end };
}

// Values are whole numbers in 0..2^31-1, so there are only 32 buckets.
// Bucket b holds values in (2^(b-1), 2^b]; bucket 0 holds 0 and 1.
function looseMedianStream() {
  const count = new Array<number>(32).fill(0);
  let n = 0;

  const bucketOf = (x: number): number => {
    let b = 0;
    while (2 ** b < x) b++; // smallest power of 2 that is >= x
    return b;
  };

  const add = (x: number): void => {
    count[bucketOf(x)]++;
    n++;
  };

  // walk the 32 buckets to the one holding the median, return its top power of 2
  const findLooseMedian = (): number => {
    const k = Math.floor((n - 1) / 2); // 0-based position of the (lower) median
    let seen = 0;
    for (let b = 0; b < 32; b++) {
      seen += count[b];
      if (seen > k) return 2 ** b;
    }
    return -1; // empty stream
  };

  return { add, findLooseMedian };
}

Q1 — Two-parent family tree: siblings, cousins, closest common ancestor
“Given an infinite ancestoral tree with child -> parent (both parents) relationship.” Are two people siblings? Follow-ups: first cousins, then the lowest common ancestor. “every node here has two parents”.
🔍 No LeetCode match
LC 236 — Lowest Common Ancestor of a Binary Tree LC 1650 — Lowest Common Ancestor of a Binary Tree III
💡 Climb from both people one generation at a time (BFS upward), remembering how far up each ancestor is. A person reached from both sides is a candidate; stop once the round number reaches the best total.
⚠️ Assumptions: siblings share at least one parent; first cousins share a grandparent but are not siblings; “lowest” = fewest total generations from both (ties: any one). With no common ancestor in an infinite tree the search never ends, so ask for a generation limit.
⏱️ TC: siblings/cousins O(1); LCA O(2^k), k = generations to the answer, since each generation can double the ancestors
📦 SC: O(2^k), the two depth maps (LCA)
🧪 Checked against brute force on 40,000 random family graphs: 0 mismatches.
familyTree.ts
// getParents(p) returns p's known parents (0, 1 or 2 names)
function familyTree(getParents: (p: string) => string[]) {
  const parents = (p: string) => new Set(getParents(p));
  const grandparents = (p: string) => new Set(getParents(p).flatMap(getParents));
  const shares = (x: Set<string>, y: Set<string>) => [...x].some(v => y.has(v));

  // siblings: different people with at least one parent in common
  const areSiblings = (a: string, b: string) => a !== b && shares(parents(a), parents(b));

  // first cousins: a grandparent in common, but not siblings
  const areCousins = (a: string, b: string) =>
    a !== b && !areSiblings(a, b) && shares(grandparents(a), grandparents(b));

  // closest common ancestor: smallest (generations up from a) + (generations up from b)
  const lca = (a: string, b: string): string | null => {
    const da = new Map([[a, 0]]), db = new Map([[b, 0]]);
    let best: string | null = null, bestSum = Infinity;
    const check = (x: string) => {
      if (!da.has(x) || !db.has(x)) return;
      const s = da.get(x)! + db.get(x)!;
      if (s < bestSum) { best = x; bestSum = s; }
    };
    // climb one generation; dist keeps the first (shortest) depth seen
    const up = (front: string[], dist: Map<string, number>, k: number) => {
      const next: string[] = [];
      for (const p of front) for (const g of getParents(p))
        if (!dist.has(g)) { dist.set(g, k); next.push(g); check(g); }
      return next;
    };
    check(a);
    let fa = [a], fb = [b];
    // after round k every node within k generations of both is checked,
    // so anything unseen has sum > k: stop once k + 1 >= bestSum
    for (let k = 1; k < bestSum && (fa.length || fb.length); k++) {
      fa = up(fa, da, k);
      fb = up(fb, db, k);
    }
    return best;
  };

  return { areSiblings, areCousins, lca };
}

💡 Performance never improves, so if worseCommit(lo, hi) is false the whole range is skipped. Otherwise split in half and search both halves; when two commits are neighbours, the later one is bad.
⚠️ Assumes the round asked the linked post’s version (all bad commits). Commits are 1..n; a bad commit is worse than the one right before it. The example output 4, 7 checks out.

// commits are 1..n; worseCommit(a, b) = true if b performs worse than a
function findBadCommits(n: number, worseCommit: (a: number, b: number) => boolean): number[] {
  const bad: number[] = [];

  // every drop between lo and hi lies in (lo, hi]
  const search = (lo: number, hi: number) => {
    if (lo >= hi || !worseCommit(lo, hi)) return; // no drop in this range
    if (hi === lo + 1) { bad.push(hi); return; } // neighbours: hi is a bad commit
    const mid = Math.floor((lo + hi) / 2);
    search(lo, mid);
    search(mid, hi);
  };

  search(1, n);
  return bad;
}
